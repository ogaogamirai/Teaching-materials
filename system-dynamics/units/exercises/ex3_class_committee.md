# EX3 — クラスの係活動が回らない

> 対象: 中2　使う要素: ボトルネック・負のループ
> 配置: Unit 7-8（選択式・解答なし）

---

## シチュエーション

Dさんはクラスの「体育祭実行係」です。係活動がうまく回っていません。

- 係の仕事をやる人が決まらず、Dさんに仕事が集中する
- Dさんは仕事が多いので、他の係と連絡が取れない
- 連絡が遅れると、みんなが「知らなかった」と言って協力しない
- 協力しないから、Dさんがさらに一人で仕事を抱える
- 体育祭の準備が間に合わない

## 問題（UDE）の列挙

例:

- UDE1: 仕事がDさんに集中する
- UDE2: 連絡が遅れる
- UDE3: みんなが協力しない
- UDE4: 準備が間に合わない

## 演習ステップ

1. UDEを列挙する
2. 因果でつなぐ（CRT）— 悪循環（負のループ）を見つける
3. 根本原因（Core Constraint）を特定する
4. ボトルネックの視点（Unit 5）: 「一番仕事が滞るところ」はどこか
5. 5つの集中ステップ（Unit 6）: どう直すか
6. Unit 8: 対立・Injection（あれば）
7. Teach-Back

## ヒント

- 「Dさんに集中」は結果かもしれない。その原因（根本原因）を1つ探そう
- 悪循環の輪を見つけたら、**どこで輪を切るか**を考える（Unit 8 の Injection につながる）
- ボトルネック（Unit 5）の視点: 仕事が「たまっている」場所はどこ？

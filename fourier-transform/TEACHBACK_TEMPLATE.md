# Teach-Back テキストテンプレ（D3 決定）

> 完了条件 L3 の測定器。音声なし。空欄は短文 or チップ選択。

---

## 1. 共通6欄（全ノードの30s版 / CAPの本番版）

```
【1. 何の話？】（1文）
ゴール接続: _______________________________

【2. 部品は？】（最大3つ・チップ可）
□ ________  □ ________  □ ________

【3. どう繋がる？】（因果を1本）
________ すると → ________ になり → ________ できる。

【4. 式・記号はどこ？】（入力ではなく指差し）
画面の [ A ] [ B ] [ C ] のどれが「係数」？ → ____
（またはカードをスロットへ）

【5. よくある誤解】（1つ選んで訂正）
誤解: ________________
本当は: ______________

【6. 素人への一言】（比喩）
「________みたいなもの」
```

---

## 2. 長さ

| 用途 | 目安 | 必須欄 |
|------|------|--------|
| ノード出口 30s | 60–120字総量 | 1,2,3,5 |
| CAP 本番 | 3–7分相当の記述 | 1–6 すべて |
| sprint CAP | 2–3分 | 1,2,3,5,6 |

---

## 3. ノード別プロンプト（seed）

### FT-HOOK-1（任意・短い）
- 問: JPEGっぽい画像が軽くなるとき、何が起きている？

### FT-WAVE-1
- 問: 波を決める三つのつまみを、友達に説明して。

### FT-CIRCLE-1
- 問: なぜ回る円が「波」になるの？

### FT-SUPER-1
- 問: 二つの波を足すと、いつ大きくなり、いつ消える？

### FT-SERIES-1
- 問: 円をたくさん足すと、なぜ角ばった形に近づく？

### FT-ORTHO-1
- 問: 「似ている度」で成分を取り出す、を比喩で。

### FT-COEFF-1
- 問: 係数が大きい・小さいは、画面上で何が違う？

### FT-APP-1
- 問: 画像圧縮は、何を残して何を捨てている？

### FT-CAP-1（本番）
- 問: 中学生の弟妹に、**「JPEGと波の足し算」**を教えて。  
- 制約: 複素数も e も使わなくてよい。実数の言葉で。

### FT-EULER-1（拡張）
- 問: これまで学んだ sin/cos が、回転ひとつでどうまとまる？

---

## 4. 模範の置き方

- 各ノードに `exemplar_short`（60字）と `exemplar_full`（CAP用）を用意  
- 提出後に並列表示。コピー防止より **差分学習** を優先  
- 「一言も書けない」時は欄1だけチップ作文 → それでも L3 にはしない（L1どまり）

---

## 5. UIメモ（実装時）

- textarea は各欄 2–4 行  
- 部品欄はチップ＋「その他」1つ  
- 下書き localStorage  
- 「比べる」で exemplar をトグル

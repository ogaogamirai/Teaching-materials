# Unit 2 — ストックとフロー：お風呂の水位で考える

> **対象:** 中学2年生〜一般社会人
> **ゴール（基本編 L3 Teach-Back）:** 「たまるもの（ストック）」と「流れるもの（フロー）」を区別し、変化のルールを人に説明できる
> **発展編 L5:** ストックの変化を微分方程式 `d(水位)/dt = 入り − 出` で記述できる
> **所要目安:** 基本編 15〜20分 / 発展編 10〜15分

---

# 基本編（中2〜）

## 1. Hook — お風呂の水位

お風呂にお湯をためるときのことを思い出してください。

![fig:お風呂の水位（ストック）は、蛇口から入るお湯（フローIN）と排水口から出るお湯（フローOUT）の引き算で決まる](figures/unit2_bath_illustration.svg)

水位は、どうして上がったり下がったりするのでしょう？ 実は、たった1つのルールで説明できます。

## 2. なぜこれを学ぶのか？（Value）

世の中の「たまっているもの」は、ほとんど全部このルールで動いています。

- お金（貯金がたまる）
- 水（池・貯水タンク）
- 人口（人がたまる）
- 知識・体力・フォロワー数・在庫…

**これが分かると、** 「なぜ増えたり減ったりするのか」の理由が、絵を描くだけで分かるようになります。これがシステム思考の「見る力」の基本です。

## 3. ストックとフロー — 2つの仲間（Reveal）

まず、言葉の確認から。この2つは**最初に区別する**のが大事です。

| 名前 | 意味 | お風呂の例 | 他の例 |
|---|---|---|---|
| **ストック（Stock）** | **たまっているもの**（その瞬間の量） | 水位 | 貯金・在庫・人口 |
| **フロー（Flow）** | **流れているもの**（増える/減る量） | 蛇口の水・排水口の水 | 収入・支出・出生・死亡 |

> **Point:** ストックは「今、どれだけあるか」、フローは「どれだけ流れているか」を教えてくれる。

## 4. 水位のルール（Interact）— これがUnit 2の最重要ポイント

お風呂の水位は、次の1本の式で表せます。

```
水位の変化 = 入ってくる水（蛇口） − 出ていく水（排水口）
```

このルールで、3つの場合を考えてみましょう。

| 場合 | 入りと出の関係 | 水位 |
|---|---|---|
| A | 入り > 出 | **上がる** |
| B | 入り < 出 | **下がる** |
| C | 入り = 出 | **変わらない** |

> **やってみよう:** 上の図（蛇口と排水口）を紙に書いて、それぞれの場合に水位がどうなるかを描いてみよう。
>
> **ポイント:** 「水位そのもの」ではなく「水位の**変化**」に注目しているところが大切。水位が高いか低いかではなく、**入りと出のどちらが多いか**で決まるのです。

## 5. 例で定着 — 貯金も同じ（Interact）

お風呂と同じルールで、貯金も説明できます。

| | お風呂 | 貯金 |
|---|---|---|
| ストック | 水位 | 貯金額 |
| 入り（フローIN） | 蛇口の水 | おこづかい・バイト代 |
| 出（フローOUT） | 排水口の水 | 買い物・お小遣いの支出 |
| ルール | 入り − 出 | 入り − 出 |

**「貯金が増える」＝ 入るお金 > 出るお金。** お風呂とまったく同じ構造です。これが「ストックとフロー」の考え方のすごいところ。**構造が同じなら、別の分野でも同じ見方ができる**のです。

## 6. Check — 確かめてみよう

それぞれ、ストックとフローを答えよう。

1. コップの中の水 → ストック？ フロー？
2. 蛇口から出る水 → ストック？ フロー？
3. 今日の残金 → ストック？ フロー？
4. 買い物で使うお金 → ストック？ フロー？

> **答え合わせ（下を見る前に自分で答えよう）:**
> 1. ストック　2. フロー　3. ストック　4. フロー

**おまけ問題:** 「水位が下がっている」とき、蛇口と排水口はどちらが多い？

> **答え:** 排水口（出）のほうが多い。

## 7. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「ストック＝増えるもの、フロー＝減るもの」 | そんなことはない。ストックは「たまるもの」（増えも減りもする）。フローは「流れるもの」（入りと出の両方がある） |
| 「水位が高い＝水位が上がっている」 | 水位の**高さ**と水位の**変化**は別もの。高くても、出のほうが多いと**下がる** |
| 「フローが大きい＝量が多い」 | フローは「時間あたり」の流れ。1分にどれだけ流れるか |

## 8. Teach-Back — 素人に説明しよう（基本編ゴール）

テンプレで「ストックとフロー」を、知らない人に説明してみよう。

1. **何の話か:** 物事には「たまるもの」と「流れるもの」がある、という話
2. **部品は何か:** ストック（たまるもの）・フローIN（入り）・フローOUT（出）
3. **どう繋がるか:** 変化 = 入り − 出
4. **図はどこを見ればいいか:** 蛇口と排水口の両方がある絵
5. **よくある誤解:** 水位の高さではなく、入りと出のどちらが多いかで変化が決まる
6. **素人への一言:** 「お風呂だよ。蛇口が排水口より多ければ水位は上がる。それだけ」

# 発展編（大学レベル・L4–L5）

> **必要な前提:** math-bridge の **B1〜B5**（変化率と割合 → 関数とグラフ → 瞬間の変化率 → 微分の意味 → 微分方程式の第一歩）
> 中学2年生は発展編の前に B1〜B5 を先に読もう。数学が得意な人はスキップ可。各補助Unitは10〜15分。
> math-bridge/README.md 参照。

## 9. Deepen — 「変化」を数式で書く

基本編のルールを、もう一度式で見てみましょう。

```
水位の変化 = 入り − 出
```

これは、数学の言葉ではこう書きます。

$$ \frac{d(水位)}{dt} = 入り - 出 $$

- $d(水位)$ … 水位の**ほんの少しの変化**
- $dt$ … **ほんの少しの時間**の変化
- $\frac{d(水位)}{dt}$ … **単位時間あたりの水位の変化**（＝水位の増える速さ）

つまり「変化の速さ = 入り − 出」。基本編で言葉で言ったことと、完全に同じです。**数式は、言葉のルールを短く正確にしたもの**という感覚を持てれば十分です。

> **式の読み方:** 左辺 $\frac{d(水位)}{dt}$ は「水位が増える速さ」。右辺 $入り - 出$ は「蛇口から入る量から、排水口から出る量を引いたもの」。速さ＝入りマイナス出、という言葉のルールを省略記号で書いただけ。
>
> 記号の詳しい読み解きは math-bridge の **B5**（微分方程式の第一歩）で。

## 10. Deepen — ストックフロー図（記号で描く）

システムダイナミクスでは、この構造を「ストックフロー図」という正式な記号で描きます。

```
   [蛇口]  ──▶（入り）──▶ [□ 水位] ◀──（出）──◀ [排水口]
            フローIN         ストック    フローOUT
```

| 記号 | 意味 |
|---|---|
| `□`（四角） | ストック（たまるもの） |
| `→` の矢印 | フロー（流れるもの） |
| 雲の形 | ストックの外（入り・出の供給元・行き先） |

この記号を使うと、貯金・人口・在庫が**全部同じ図**で描けるのが分かります。

## 11. Extend — 同じ構造を見つける（転移・L4）

ストックとフローは、社会のどこにでもあります。探してみよう。

- **スマホの充電**: バッテリー残量（ストック）＝ 充電（入り）− 消費（出）
- **フォロワー数**: フォロワー（ストック）＝ 増える（入り）− 減る（出）
- **部活の練習**: 技術（ストック）＝ 練習で身につく（入り）− さぼる・忘れる（出）

> **課題:** 自分の身の回りから1つ見つけて、ストックとフローに分けてみよう。

## 12. Check-L5 — 発展編の確認

1. $\frac{d(水位)}{dt} = 入り - 出$ の式で、「入り < 出」のとき $\frac{d(水位)}{dt}$ は正？ 負？ ゼロ？
2. ストックフロー図の `□` は何を表す？
3. フォロワー数が「横ばい」のとき、入りと出の関係は？

> **答え:** 1. 負（水位は下がる）　2. ストック（たまるもの）　3. 入り = 出

---

## まとめ（Takeaway）

- **ストック** = たまっているもの（水位・貯金・人口）
- **フロー** = 流れているもの（入り・出）
- **変化 = 入り − 出** が基本のルール。お風呂も貯金も人口も同じ構造
- 数式では $\frac{d(水位)}{dt} = 入り - 出$。言葉のルールを正確にしただけ（詳しくは math-bridge B5）
- 次回は「変化の結果が、また変化を生む」フィードバックループを見ていく

> **次回予告 (Unit 3):** 「増えると→もっと増える」の正のループと、「増えると→止める」の負のループ。

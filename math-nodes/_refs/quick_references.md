# 前提知識クイックリファレンス（C類：日常・小学校層）

ノード化しない前提知識の一行参照。教材の「前提ノードと入口判定」表から参照される。

| 知識 | 一言 | 使うノード |
|---|---|---|
| 数直線 | 数を「位置」で表す直線。右が大きい。その左の数（負）も実在 | JH-NUM-SIGN-01 |
| 座席表（2 列目の 3 番目） | 2 つの情報（列・番号）で位置を指定する感覚 | JH-COORD-PLANE-01 |
| 比例の感覚 | x が 2 倍なら y も 2 倍。原点を通る直線のグラフ | JH-FUNC-LINEAR-01 |
| 底辺と高さ | 三角形の面積 = 底辺 × 高さ ÷ 2 | HS1-TRIG-AREA-01 |
| 直角三角形の辺の名称 | 直角を挟む 2 辺は直角を挟む、斜辺は直角の向かい側 | HS1-TRIG-DEF-01 |
| 分数の割り算 | 割り算は逆数を掛ける（÷ 2/3 = × 3/2） | HS1-TRIG-IDENTITY-01 |
| 60°・45°・30° の三角比 | 正三角形を半分に切る／直角二等辺三角形 | HS1-TRIG-UNITCIRCLE-01 ほか |

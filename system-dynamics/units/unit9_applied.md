## 1. Hook — 実務の問題にも「構造」がある

職場では、こんな問題がよくあります。

- 会議ばかりで仕事が進まない
- 残業が減らない
- 売上が伸びない
- 値下げしたのに利益が減った

どれも「人手が足りない」「努力が足りない」と片付けられがちですが、実は**構造（ループ・ボトルネック・対立）** が原因であることが多い。このUnitでは、Unit 1〜8 で学んだ全部を使って、実務の問題を解きます。

## 5. 例題（EX9: 値下げの罠）— 解答つき

値下げで「売上は増えたのに利益が減った」問題を、3つの視点で解いてみる。

### Step2: UDEの列挙

- UDE1: 利益が減った
- UDE2: 1個あたりの利益率が下がった
- UDE3: 販売数は増えたのに儲かっていない
- UDE4: コスト（発送・返品）が増えた

### Step3: 構造を見る（SD）

**ストックとフロー（Unit 2）:**

```
売上（フローIN）──▶ [利益（ストック）] ◀── 費用（フローOUT）
```

**2つのループ（Unit 3）:**

```
【正のループ】 値下げ → 販売数増 → 売上増 → さらに値下げ
【負のループ】 値下げ → 利益率減 → 利益減 → 投資ができない → 品質低下 → 販売減
```

「今」は正のループ（売上増）が見えているが、**負のループ（利益率減）が後から効いてくる**（時間の遅れ・Unit 4）。

### Step4: 制約を直す（TOC・Unit 5-6）

ボトルネックは「販売数」か？ それとも「利益率」か？

→ 利益（ストック）を増やすには、**利益率（1個あたりの儲け）** がボトルネック。5ステップで言えば「強化（ステップ4）」ではなく、まず「活用・従属（2・3）」で利益率を改善できないか考える。

### Step5: 根本原因（CRT・Unit 7）

- 根本原因: 「**利益（ストック）ではなく売上（フローIN）で判断している**」という見方の構造
- つまり「売上 = 良し」という思い込みが、値下げの罠の根本原因

### Step6: 解消する（Injection・Unit 8）

**蒸発する雲:**

```
        [目的C] 長期的に儲け続ける（事業を続ける）
        ／                              ＼
  [要求A] 売上を増やしたい            [要求B] 利益率を守りたい
     │                                    │
  [行動A] 値下げする          ←→    [行動B] 値段を維持する
```

**前提（思い込み）:** 「売上を増やす = 値下げしかない」

**Injection（前提を外す）:** 値下げ以外で売上を増やす方法
- 付加価値を上げる（品質・サービス・デザインで差別化）
- セット販売・定期購入で客単価を上げる
- ボトルネック（EX10）の視点で、儲かる商品に集中する

→ 「売上」と「利益率」の対立が、前提を外すことで蒸発する。

### Step7: FRT（新たな問題）

- 付加価値アップ → 価格に見合わないと思われる？
  → 対策: 実績・レビューを可視化する
- セット販売 → 在庫が増える？
  → 対策: 需要予測・限定数でリスク抑制

### Step8: Teach-Back

「値下げの罠は、売上（フロー）を見て利益（ストック）を見ていないから起きる。利益率という制約を直し、値下げ以外で売上を増やす仕組みを作ると、対立が解ける」

## 6. 例題（EX10: ボトルネックと価格）— 解答つき

スループット会計（TOC）の核心。カード `exercises/ex10_bottleneck_pricing.md` を参照。

### 計算

| 製品 | 粗利 | ボトルネック時間 | 1分あたり |
|---|---|---|---|
| A | 1,000−500 = 500円 | 10分 | **50円/分** |
| B | 800−400 = 400円 | 5分 | **80円/分** |

- Aだけ（480÷10=48個）: 48×500 = **24,000円**
- Bだけ（480÷5=96個）: 96×400 = **38,400円**

→ **価格の高いAより、ボトルネック1分あたりの儲けが大きいBを優先**すると、全体の利益が大きい。

### なぜこれが大事か

「1個の儲け」ではなく「**制約（ボトルネック）の時間あたりの儲け**」で判断する。これがTOCのスループット会計。限られた資源（機械時間）を最も効率よくお金に変える。

### 発展

ボトルネックを強化（Unit 6 ステップ4）すれば、AもBも作れるようになり、さらに利益を増やせる。

## まとめ（Takeaway）

- 実務の問題は「人手不足・努力不足」ではなく**構造**が原因のことが多い
- 3つの視点を順番に使う: **見る（SD）→ 直す（TOC）→ 解く（CRT+Injection）**
- **価格戦略（EX9・EX10）** は、SD（利益のストック）とTOC（ボトルネック×価格）の両方で解ける絶好の題材
- スループット会計: 制約の時間という貴重な資源を、1分あたりの儲けが大きい方に使う
- 次回は全ユニットの総仕上げ（抽象化）

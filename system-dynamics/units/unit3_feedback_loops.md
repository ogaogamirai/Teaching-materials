# Unit 3 — フィードバックループ：増えると、どうなる？

> **対象:** 中学2年生〜一般社会人
> **ゴール（基本編 L3 Teach-Back）:** 「正のループ（強化）」と「負のループ（調整）」を見分け、結果が原因に返ることを自分の言葉で説明できる
> **発展編 L5:** 正のループが指数成長になることを数理（e・倍々）で説明できる
> **所要目安:** 基本編 15〜20分 / 発展編 10〜15分

---

# 基本編（中2〜）

## 1. Hook — YouTubeのフォロワー数

動画を投稿する人のフォロワー数を想像してください。

1. 動画を投稿する → フォロワーが少し増える
2. → フォロワーが多いと「人気だ」と見る人が増える
3. → 再生回数が伸びる → おすすめに出やすくなる
4. → さらにフォロワーが増える → **1に戻る**

「増えた（結果）」が「さらに増やす（原因）」に**返ってきています**。これがフィードバックループです。

## 2. なぜこれを学ぶのか？（Value）

Unit 2 で「ストックとフロー」を学びました。しかし、そこでは「フローは外から一定に来る」として考えました。

実際には、**ストックの量がフロー自体を変える**ことがよくあります。これを扱うのが「フィードバックループ」です。これを学ぶと、世の中の「雪だるま式の増え方」「ちょうどいいところで落ち着く」が、絵を描くだけで説明できるようになります。

## 3. 2種類のループ（Reveal）

ループは2種類あります。**最初に区別**しておきましょう。

### ① 正のループ（強化ループ）—「増えると、もっと増える」

```
フォロワー（ストック）
   │
   ▼
見る人が増える ──▶ さらにフォロワーが増える ──▶ さらに見る人が増える…
```

- 増えるとますます増える（減るとますます減る）
- 雪だるま式・倍々ゲーム
- 例: YouTubeフォロワー・うわさ・風邪の流行・貯金の利子

### ② 負のループ（調整ループ）—「増えると、止める方向に働く」

```
室温（ストック）
   │
   ▼
「暑い」と感じる ──▶ エアコンを下げる ──▶ 室温が下がる ──▶ 「ちょうどいい」
```

- 増えると減らす方向に、減ると増やす方向に働く
- バランスを取って「ちょうどいい」に落ち着く
- 例: 室温調整・満腹・混雑回避

![fig:正のループ（増えるともっと増える）と負のループ（増えると抑える）](figures/unit3_feedback_loops.svg)

## 4. ループの図の書き方（Interact）

ループを図にするときの基本形：

```
       ┌───────────┐
       ▼           │
  [ストック]        │
       │           │
       ▼           │
  [フローを変える] ─┘
```

- **＋（プラス）**: 増えると増える方向
- **−（マイナス）**: 増えると減らす方向
- 輪（ループ）になっていることが大事

> **やってみよう:** 上の「YouTubeフォロワー」と「室温」を、この形の図に書いてみよう。どちらが＋の輪で、どちらが−の輪か、印をつけよう。

## 5. 例で定着 — 正と負を見分ける（Interact）

| 場面 | どんなループ？ |
|---|---|
| 風邪が流行る（うつす→増える→さらにうつす） | 正（雪だるま） |
| 満腹になる（食べる→お腹いっぱい→食べるのをやめる） | 負（バランス） |
| 貯金の利子（貯まる→利子がつく→さらに貯まる） | 正 |
| 行列が混むと避ける（混む→避ける→空く） | 負 |

**見分け方のコツ:**

> 「増えた結果、**さらに増やす**方向なら正。**減らす（抑える）**方向なら負。」

## 6. Check — 確かめてみよう

それぞれ正のループ？ 負のループ？

1. ゲームで勝つ→自信がつく→さらに練習する→もっと勝つ
2. お腹が空く→食べる→満腹→食べるのをやめる
3. 夜更かしする→朝起きられない→夜更かしする（悪循環）
4. 混んでいる電車→空いてる方へ移動→混雑が分散する

> **答え（下を見る前に自分で）:**
> 1. 正　2. 負　3. 正（悪い雪だるま）　4. 負

## 7. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「正のループ＝良いもの、負のループ＝悪いもの」 | 正・負は「増える/抑える」の方向であって、善悪ではない。悪い雪だるま（夜更かしの悪循環）も正のループ |
| 「負のループ＝減るだけ」 | 違う。負のループは「減らし過ぎたら増やす」こともする。要は**バランスを取って一定に落ち着かせる** |

## 8. Teach-Back — 素人に説明しよう（基本編ゴール）

テンプレで「2種類のループ」を説明しよう。

1. **何の話か:** 「増えるとどうなるか」には2種類ある、という話
2. **部品は何か:** 正のループ（強化）・負のループ（調整）・ストック
3. **どう繋がるか:** 増えた結果が原因に返る。さらに増やすか、抑えるか
4. **図はどこを見ればいいか:** 輪になっていること。＋の印か−の印か
5. **よくある誤解:** 正のループが良いとは限らない
6. **素人への一言:** 「YouTubeのフォロワーだよ。増えるともっと増える（正）と、暑いから冷やす（負）がある」

# 発展編（大学レベル・L4–L5）

> **必要な前提:** math-bridge の **B6**（指数成長・減衰と e・ln）。中2は発展編の前に B6 を読もう。
> math-bridge/README.md 参照。

## 9. Deepen — 正のループは「倍々」になる

正のループ（増えるともっと増える）を数式で見てみましょう。

ストックの増える速さが「今ある量に比例する」とき：

$$ \frac{d(ストック)}{dt} = r \times ストック $$

- $r$ … 増えやすさ（正の数）
- 右辺に「ストック」自身が入っているのがポイント

これは「今の量に比例して増える」= **倍々ゲーム**です。これを解くと：

$$ ストック(t) = ストック(0) \times e^{r t} $$

- $e$ … 約2.718…の特別な数（自然対数の底）
- $e^{r t}$ … 時間とともに爆発的に大きくなる
- これが**指数成長**

**意味:** 正のループをそのまま放っておくと、量は直線ではなく**どんどん加速して増える**（雪だるまが大きくなるほど転がるのが速くなる）。

## 10. Deepen — 負のループは「収束」する

負のループ（増えると抑える）では、量が目標値に近づくほど、増える速さが弱まります。

$$ \frac{d(ストック)}{dt} = k \times (目標 - ストック) $$

- ストックが目標より小さい → 右辺が正（増える）
- ストックが目標に近づく → 右辺が小さくなる（増え方が鈍る）
- ストック = 目標 → 右辺 = 0（変化なし）

**意味:** 負のループは、量を目標に**なめらかに近づけて、そこに落ち着かせる**。これが「ちょうどいい」に落ち着く理由の数理です。

## 11. Extend — 正と負の組み合わせ（転移・L4）

現実のシステムは、正と負が**混ざって**います。

- **風邪の流行**: 流行の初期は正のループ（拡大）→ 免疫ができる・対策する負のループ（抑制）が強まって、頭打ちになる
- **人気商品**: 売れて人気が出る正のループ → 在庫切れ・飽きられる負のループで落ち着く

> **課題:** 「成長するけど、どこかで頭打ちになる」ものを1つ見つけて、正と負のループを1つずつ指摘してみよう。

## 12. Check-L5 — 発展編の確認

1. 正のループ（倍々）のグラフの形は？
2. 負のループは最終的にどこに落ち着く？
3. $r > 0$ のとき、$e^{r t}$ は時間とともにどうなる？

> **答え:** 1. 加速する曲線（指数成長）　2. 目標値　3. 爆発的に大きくなる

---

## まとめ（Takeaway）

- **正のループ**（＋）: 増えるともっと増える。雪だるま式。放っておくと指数成長
- **負のループ**（−）: 増えると抑える。バランスを取って目標に落ち着く
- 見分け方: 「増えた結果、さらに増やすか、抑えるか」
- 数理: 正＝指数成長（$e^{rt}$）、負＝目標への収束
- 次回は「変化がすぐに効かない」ときの話

> **次回予告 (Unit 4):** 「効き目が後から出る」時間の遅れ。

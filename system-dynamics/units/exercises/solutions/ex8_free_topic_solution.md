## 2. 架空の見本テーマ:「読書習慣が続かない」

### ① 参照モード
「読書しよう」と意気込むが、1週間で止まる。これを繰り返している。

### ② 構造を見る（ループ）
```
本を読む → 眠くなる・退屈
   ▼
「今度こそ」と本を買う
   ▼
読む時間を作れない（ゲーム・SNSに時間を取られる）
   ▼
読書が習慣にならない
   ▼
（最初に戻る＝悪循環）
```

**遅れ:** 読書の効果（知識・面白さ）は後から出る。ゲーム・SNSの楽しさは即時。だから「今楽しい方」に流れる。

### ③ 介入点・政策抵抗
- 介入点: ゲーム・SNSの**正のループを切る**（時間を決める）、読書の**入り口を易しくする**（短い本・好きなジャンルから）
- 政策抵抗: 「頑張って読もう」だけでは、SNSの即時快楽ループに打ち消される

### ④ 制約・根本原因
- 制約: **読書のための時間**（他のことに取られている）
- 根本原因（CRT）: 「読書の効果（遅れて出る）と、SNSの効果（即時）のバランス」— 遅れのある活動は、即時の活動に負ける

### ⑤ 解消（対立の解体）
```
[目的C] 楽しく過ごしたい & 成長したい
   ／                          ＼
[要求A] 今を楽しくしたい      [要求B] 後で役立つことを身につけたい
   │                              │
[行動A] SNS・ゲームに時間を費やす ←→ [行動B] 読書の時間を作る
```

**前提:** 「今楽しいこと」と「後で役立つこと」は両立しない、という思い込み。

**Injection:** 「楽しい」読書を選ぶ（好きなテーマの本）。**読書も「今楽しい」に変える**と、対立が消える。さらに、読書の時間をSNSと同じ「習慣の仕組み」に載せる（毎日10分、決まった時間）。

### ⑥ FRT
- 短い本から始める → 物足りない？
  → 対策: シリーズもの・続きが気になる本を選ぶ

### ⑦ Teach-Back
「読書が続かないのは、意志が弱いからではなく、SNSの即時快楽ループに負けるから。読書も『今楽しい』に変えて、習慣の仕組みに載せれば続く」

## 3. 自分のテーマを解くときのコツ

- テーマは「うまくいっていない」と感じるものなら何でも良い
- **構造を描くことを必ずやる**（頭の中だけはNG。図にすると見える）
- 最後は必ず Teach-Back（人に説明できる＝本当に分かった）

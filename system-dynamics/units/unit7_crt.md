# Unit 7 — 演習A（基本編）: CRTを作る — 現状問題ツリーで「本当の原因」を見つける

> **対象:** 中学2年生〜一般社会人
> **ゴール（L3 Teach-Back）:** 「個別対策では解決しない理由」と「根本原因（Root）に集中すると効率的に解決できる」ことを、自分の言葉で説明できる。CRTで根本原因を1つ特定できる
> **所要目安:** 20〜30分（例題つき）
> **準備:** 演習カード `exercises/ex1_getting_up.md`（例題）を手元に

---

## 1. Hook — まず「朝起きられない」を直してみよう（体験）

Aさんは朝起きられずに困っています。原因は「よく分からない」まま、いろいろ試してみました。

| 試した対策 | 結果 |
|---|---|
| 「朝ごはんを食べるようにした」 | 変わらない（そもそも食べる時間がない） |
| 「授業を楽しくしようと頑張った」 | 眠くなるのは変わらない |
| 「スマホをやめようとした」 | 1日は我慢できるけど、また戻る |
| 「疲れを取ろうと早く寝ようとした」 | なぜか夜更かししてしまう |

**全部、それっぽいのに、ぜんぜん解決しません。**

> **ここが大事な体験です。** 原因が分からないまま対策を打つと、症状を1個ずつ追いかける「モグラ叩き」になり、どれも根本からは直りません。

## 2. なぜ個別対策では解決しないのか（Value）

### 症状は「枝」で、原因は「根」にある

木を想像してください。枯れているのは**葉っぱ（症状）**ですが、問題の本当の場所は**根（根本原因）**にあります。

```
    葉っぱ（症状）: 朝起きられない・眠い・朝ごはんを食べられない・疲れてる…
       │
       │ （葉っぱを1枚ずつ直しても、根がダメならまた枯れる）
       ▼
     根（根本原因）: 夜更かし  ← ここを直すと、葉っぱがまとめて元気になる
```

- **個別対策** = 葉っぱを1枚ずつ治そうとする（モグラ叩き・非効率）
- **根本対策** = 根を1本直す（葉っぱがまとめて良くなる・効率的）

**この「根を見つけて、そこに集中する」ことが、合理的で効率的な解決の第一歩です。**

### CRTの意義（このUnitの核心）

> **「原因が分かりにくい状態」から、因果関係でつなぎ合わせることで「根（Root）」を1つに絞り込む。それがCRT（現状問題ツリー）を作る意義です。**

- CRTを作る前: 原因がいくつもあるように見えて、何を直せばいいか分からない
- CRTを作った後: **Root（根本原因）が1つに見える**。直す場所が決まる

## 3. CRTとは（Purpose→Meaning）

### Purpose（目的）
問題（UDE）を因果関係でつないだ「木のような図」を作り、**Root（根本原因）を1つに絞り込む**。

### Meaning（意味）

| 用語 | 意味 |
|---|---|
| **UDE**（Undesirable Effect） | 現状の不都合な事象（症状・観測できる問題） |
| **CRT**（Current Reality Tree） | 現状問題ツリー。UDEを「なぜなら」でつないだ図 |
| **Core Constraint / Root** | 根本原因。矢印が一番多く「原因」として出ているノード |

## 4. CRTの作り方（4ステップ）

```
Step1 問題（UDE）を列挙する
   ↓ 原因や解決策を混ぜず、「観測できる症状」を1項目1文で
Step2 因果でつなぐ
   ↓ 「Aが起きる、なぜならBだから」の矢印で結ぶ
Step3 輪（ループ）を探す
   ↓ 悪循環（負のループ）があれば、それが「現状が続く理由」
Step4 Root（根本原因）を特定する
   ↓ 「原因」として矢印が一番多く出ているノードが Core Constraint
```

## 5. 例題（EX1: 朝起きられない）— Rootが見える体験をしよう

「原因が分からない」状態から、CRTを作って Root を1つに絞る体験を追います。

### Step1: まず症状（UDE）を、原因を混ぜずに書き出す

「夜更かし」と「スマホ」は**原因**かもしれないので、ここでは書かない。観測できる症状だけを書く。

| # | UDE（観測できる症状） |
|---|---|
| UDE1 | 朝、起きられない |
| UDE2 | 朝ごはんを食べられない |
| UDE3 | 授業中に眠くなる |
| UDE4 | 家に帰ると疲れている |

### Step2: 「なぜなら」でつなぐ

「Aが起きるのは、なぜならBだから」の矢印で、症状同士をつないでいく。

```
[朝、起きられない]
   │ なぜなら
   ▼
[朝ごはんを食べられない]
   │ なぜなら（起きるのが遅くて時間がない）
   ▼
[授業中に眠くなる]
   │ なぜなら
   ▼
[家に帰ると疲れている]
```

ここで「家に帰ると疲れている」の**原因**をさらに考えてみると…

> 「疲れている」のはなぜ？ → **睡眠不足**。睡眠不足はなぜ？ → **夜更かし**。夜更かしはなぜ？ → **寝る前にスマホを見てしまう**。

これを矢印で追加する。

```
[夜更かししてしまう] ←── [寝る前にスマホを見てしまう]
   │ なぜなら（睡眠不足になる）
   ▼
[朝、起きられない]
   │
   ▼
[朝ごはんを食べられない]
   │
   ▼
[授業中に眠くなる]
   │
   ▼
[家に帰ると疲れている]
   │
   ▼
[夜更かししてしまう]  ←（輪になっている！）
```

### Step3: 輪（ループ）を見つける

この図は**輪になっています**。「夜更かし→朝起きられない→眠い→疲れ→また夜更かし」という**悪循環（負のループ）**。だから、1つの対策では止まらずにぐるぐる回り続けます。これが「個別対策で解決しない」理由です。

### Step4: Root（根本原因）を特定する

「原因」として矢印が一番多く出ているのはどこ？

- 「朝起きられない」は矢印が**入ってくるだけ**（結果）
- 「朝ごはんを食べられない」「眠くなる」「疲れている」も**結果**
- **「夜更かししてしまう」** から矢印が出て、すべての症状へ流れている

> **Root（根本原因）= 夜更かし（寝る時間が遅い）**

### ここで何が変わったか（体験のまとめ）

- CRTを作る前: 「朝ごはん？」「スマホ？」「疲れ？」と対策がバラバラ（モグラ叩き）
- CRTを作った後: **「夜更かし」に集中すればいい**と、直す場所が1つに決まった

**Rootを直すと、複数の症状がまとめて改善し始めます**（朝起きられる→朝ごはんを食べられる→眠くならない→疲れがたまらない）。これが「Rootにフォーカスする合理性」です。

> **ここまでがCRTの意義。** 次は Root（夜更かし）をどう解消するか（Unit 8 で）。

## 7. Check — 確かめてみよう

1. 「個別対策（モグラ叩き）」がうまくいかない理由は？（ヒント: 葉っぱと根）
2. CRTを作ると、何が「見える」ようになる？
3. Root（根本原因）は、図のどこを見れば分かる？
4. CRTが輪（ループ）になっていたら、それは何を表す？

> **答え（下を見る前に自分で）:**
> 1. 症状（葉っぱ）を1個ずつ直しても、根本原因（根）がダメならまた戻るから
> 2. 根本原因（Root）が1つに絞られて、直す場所が決まる
> 3. 「原因」として矢印が一番多く出ているノード
> 4. 悪循環（負のループ）。現状が続く理由。1つの対策では止まらない

## 8. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「原因が分からなくても、とにかく何か対策すればいい」 | 原因が分からない対策はモグラ叩き。まず構造を見る（CRT）のが先 |
| 「原因を全部直すのが良い」 | 根本原因1つを直すと複数の症状がまとめて良くなる。全部直すのは非効率 |
| 「解決策から考えてOK」 | 先に「原因（構造）」を特定する。解決策（Injection）は Unit 8 |
| 「原因と症状が混ざってOK」 | UDEは「観測できる症状」だけ。原因・解決策を混ぜるとRootが見えなくなる |

## 10. Teach-Back — 素人に説明しよう

1. **何の話か:** 「問題の本当の原因（根）を1つ見つけると、効率的に解決できる」という話
2. **部品は何か:** UDE（症状）・矢印（因果）・CRT・Root（根本原因）
3. **どう繋がるか:** 症状を「なぜなら」でつなぐと、悪循環の輪と、矢印が一番出るRootが見つかる
4. **図はどこを見ればいいか:** 矢印が一番多く「原因」として出ているノード
5. **よくある誤解:** 個別対策（モグラ叩き）は解決しない。Rootに集中する
6. **素人への一言:** 「木でいうと、葉っぱを1枚ずつ直しても枯れ続けるよ。根っこ（夜更かし）を直すと、葉っぱが全部元気になる」

## まとめ（Takeaway）

- 原因が分からないままの対策は**モグラ叩き**。症状（葉っぱ）を直しても、根（Root）がダメなら戻る
- **CRT** = 症状を「なぜなら」でつないで、**Root（根本原因）を1つに絞り込む**道具
- CRTが輪（ループ）なら、それは悪循環。だから1つの対策では止まらない
- **Rootに集中する**と、複数の症状がまとめて改善する。これが合理的で効率的な解決
- 次回は Root（根本原因）をどう解消するか（蒸発する雲・Injection）

> **次回予告 (Unit 8):** 見つけた Root を、対立の解体で「根本から解消」する。

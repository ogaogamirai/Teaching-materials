## 0. 設計思想 — 積み上げ型との決定的な違い

| | theory-v2 | theory-v3 |
|---|---|---|
| 入口 | 「なぜフーリエか」の宣言 → 理論を A→E で積み上げ、応用は最後 | **G0 で圧縮とスペクトルの「魔法」を体験** → 謎を解きに行く旅 |
| 各章の始まり | 定義・前提の整備 | **前章が生んだ疑問**（「では分解はどうやる？」） |
| 前提（積分・複素） | 本編 B′/D0 で先回りして整備 | **必要になった瞬間に、その場で最小限だけ**（inset box「足場を渡す」） |
| 応用 | Part E（最後） | G0 で予告 → G8 で答え合わせ。常にゴールが視界にある |

### 執筆の型（全章共通）

1. **冒頭 = 疑問:** 前章末尾の問い or ゴールへの接続を 1 行で掲げる
2. **本文 = 再配置:** v2 の検証済み数式・証明・図は**内容そのまま**持ち込む（式番号の連番は v3 内で振り直す）
3. **足場 inset:** 新しい道具（積分・極限・複素…）が出てきたら、本文の流れを止めず `> 🪜 足場を渡す` ブロックで最小限だけ注入し、詳細は v2 の該当章を参照させる
4. **章末 = 次の疑問:** 「ここまで来た。でも〇〇がまだ説明できない」という引きを作る
5. **導出ノート:** 公式章には「前提 → 変形 → 結論」の再現欄（v2 §5 の原則を継承）

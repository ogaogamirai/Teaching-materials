# Unit 5 — ボトルネック：一番遅いところが全体を決める

> **対象:** 中学2年生〜一般社会人
> **ゴール（基本編 L3 Teach-Back）:** 「一番遅いところ（ボトルネック）が全体の速さを決める」ことを説明でき、例で示せる
> **発展編 L5:** 待ち行列（キュー）の基礎で、ボトルネックに「たまる」ことを数理で説明できる
> **所要目安:** 基本編 15〜20分 / 発展編 10〜15分

# 基本編（中2〜）

## 1. Hook — 運動会のリレー

運動会のリレーを思い出してください。チームの速さを決めているのは、だれでしょう？

- 一番速い人？ → いいえ
- 平均的な走者？ → いいえ

**答え: 一番遅い人。** バトンが一番遅い人に届くと、そこでチーム全体が待たされるからです。

一番遅い走者を速くすれば、チーム全体が速くなります。でも、一番速い走者をさらに速くしても、全体はあまり変わりません（次の遅い人が待たされるだけ）。

> これがこのUnitのすべて。「**一番遅いところが、全体を決める**」

## 2. なぜこれを学ぶのか？（Value）

Unit 1〜4 で「構造を見る力（SD）」を学びました。では、見えた構造の中で**どこに手を打つべきか**？ これがTOC（制約理論）の出番です。

TOC の答えは一言です。

> **「一番遅いところ（ボトルネック＝制約）を直せば、全体が速くなる。」**
> 逆に、それ以外をいくら頑張っても、全体は速くならない。

これを知っていると、「どこを直すか」が迷わず決まります。**全体を平均的に頑張るより、一番遅い1箇所に集中**するほうが圧倒的に効率的です。

## 3. ボトルネックとは（Reveal）

> **ボトルネック = システム全体の速さを決めている、一番遅い（能力が小さい）部分**

名前の由来は「瓶の首」。瓶から液体を注ぐとき、速さを決めるのは瓶の口の太さです。胴体がどんなに太くても、首が細ければそこに詰まる。

```
【瓶】
 ┌─────────────┐
 │  どんなに太くても      │
 │  ここの太さは関係ない    │
 └──────┬──────┘
         ▼
        ─────   ← 瓶の首（ボトルネック）
                 ここが細いと、全体の速さがここで決まる
```

## 4. 工場の例（Interact）— 一番分かりやすい図解

複数の工程が流れて、最後に1つの製品になる工場を想像してください。

![fig:工場のボトルネック — 材料A/B/Cはそれぞれ工程1/2/3を通り、工程4（組み立て）で合流する。工程4が遅いと、そこに在庫がたまる](figures/unit5_bottleneck.svg)

工程1・2・3 がいくら速くても、**工程4（組み立て）が遅いと、製品はそこに並んで待つ**だけです。

- 工程4 が「1時間に10個」しか作れない
- 工程1・2・3 が「1時間に20個」作っても、**完成品は1時間に10個**
- 余った10個分は、組み立ての前に**たまっていく（在庫になる）**

**つまり:** 全体の生産速度は、**工程4（ボトルネック）の速度そのもの**。工程1〜3を頑張っても、完成品は増えません。

> **やってみよう:** 上の図で、ボトルネック（全体の速さを決めているところ）を指さしてみよう。また、どこを直せば全体が速くなるか、丸をつけよう。

## 5. 例で定着 — 身近なボトルネック（Interact）

| 場面 | ボトルネック（一番遅いところ） |
|---|---|
| 運動会のリレー | 一番遅い走者 |
| お店のレジ | 列をさばくレジ（待たせているところ） |
| 給食の配膳 | 一番時間のかかる作業（ご飯を盛る？ おかずを分ける？） |
| 宿題 | 一番苦手な科目（ここに時間がかかる） |
| 工場 | 一番生産が遅い工程（上記の例） |

**共通点:** 「一番遅いところ」にモノや人が**たまる**。だから、どこがボトルネックかは「**どこに行列ができているか**」を見れば分かります。

## 6. Check — 確かめてみよう

1. チームの速さを決めるのは、リレーのどの走者？
2. 工場で、完成品の数が「1時間に10個」で頭打ちなのは、どこが原因？
3. ボトルネックを見つける手がかりは？（ヒント: どこに何がたまる？）

> **答え（下を見る前に自分で）:**
> 1. 一番遅い走者　2. 一番生産が遅い工程（組み立て）　3. モノや人がたまっている（行列ができている）ところ

## 7. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「みんなで頑張れば全体が速くなる」 | ボトルネック以外を頑張っても、全体は速くならない。頑張りはボトルネックに集中すべき |
| 「一番大切な工程を直せばいい」 | 「大切」ではなく「**一番遅い**」が基準。速くても重要でも、ボトルネックでなければ全体は変わらない |
| 「ボトルネック＝ボトルネック以外の人が暇でいい」 | 待ちが生まれるのは仕組みの問題。直すべきはボトルネックの能力で、他の工程が暇になるのは別の問題 |

## 8. Teach-Back — 素人に説明しよう（基本編ゴール）

テンプレで「ボトルネック」を説明しよう。

1. **何の話か:** 「一番遅いところが全体を決める」という話
2. **部品は何か:** ボトルネック（一番遅いところ）・それ以外の工程・完成品
3. **どう繋がるか:** 一番遅いところにモノがたまり、全体の速さがそこに決まる
4. **図はどこを見ればいいか:** 瓶の首・工場でモノが並んで待っているところ
5. **よくある誤解:** みんなで頑張れば速くなる、ではない
6. **素人への一言:** 「リレーだよ。チームの速さは一番遅い人で決まる。だからそこを鍛えるのが一番効く」

# 発展編（大学レベル・L4–L5）

> **必要な前提:** math-bridge の **B1〜B5**（ストックフローの数理）。中2は先に読もう。

## 9. Deepen — ボトルネックに「たまる」を数理で見る

工場の例を、Unit 2 で学んだストックフローで考えると、ボトルネックの前には「**在庫（ストック）**」ができます。

```
入ってくる個数(フローIN) ──▶ [ボトルネック前の在庫] ◀── 出ていく個数(フローOUT)
                                ↑ここにたまる
```

ボトルネックの処理能力（出）より入ってくる量（入り）が多ければ、在庫が増えます。

$$ \frac{d(在庫)}{dt} = 入ってくる個数 - 処理できる個数 $$

- 入り > 処理 → 在庫が増える（行列が伸びる）
- 入り = 処理 → 在庫は一定（行列は変わらない）
- 入り < 処理 → 在庫が減る（行列が短くなる）

**全体の生産量 = ボトルネックの処理能力。** 入ってくる量がどれだけ多くても、出ていく量（完成品）はボトルネックの能力で頭打ちになります。これが「**制約が全体を決める**」の数理です。

![fig:在庫の蓄積 — 流入（IN）が処理能力（OUT）を上回っている間、在庫（ストック）は増え続ける。「入り = 出」で横ばいになる](figures/unit5_inventory_accumulation.svg)

## 10. Deepen — 待ち行列（キュー）の基礎

ボトルネックに「たまる」ことを学ぶのが**待ち行列理論**です。

| 要素 | 意味 |
|---|---|
| 到着率 $\lambda$ | 1時間に何個（何人）来るか |
| サービス率 $\mu$ | 1時間に何個（何人）処理できるか |

- $\lambda < \mu$ … 処理が追いつく。待ちは伸びない
- $\lambda > \mu$ … 処理が追いつかない。待ち行列が**伸び続ける**
- $\lambda = \mu$ … ぎりぎり。ほんの少し乱れると行列が伸び始める

> **直感:** レジの処理速度（$\mu$）よりお客さんが来る速さ（$\lambda$）が速いと、行列は際限なく伸びる。処理を速くするか、客の到着を減らすしかない。

## 11. Extend — 改善の指針（転移・L4）

ボトルネック思考の実践:

1. **見つける**: どこにモノ・人がたまっているか（＝ボトルネック）
2. **活用する**: ボトルネックの能力を最大限使う（アイドル時間を減らす）
3. **従属させる**: それ以外の工程は、ボトルネックに合わせて動く（作りすぎない）
4. **強化する**: ボトルネックの能力そのものを上げる
5. **繰り返す**: 直すと次のボトルネックが現れる（→ Unit 6）

> **課題:** 自分の生活（勉強・部活・家事）で「ボトルネック」を1つ見つけ、どう直すか考えてみよう。

## 12. Check-L5 — 発展編の確認

1. 到着率 $\lambda$ がサービス率 $\mu$ より大きいとき、待ち行列はどうなる？
2. 全体の生産量は、何で決まる？
3. ボトルネックの前で「たまるもの」は何？

> **答え:** 1. 伸び続ける　2. ボトルネックの処理能力　3. 在庫（待ち行列）

## まとめ（Takeaway）

- **ボトルネック** = 一番遅いところ。全体の速さを決める
- 見つけ方: 「**どこにたまっているか**」（在庫・行列）
- ボトルネック以外を頑張っても全体は速くならない。**集中**が効率の鍵
- 数理: 待ち行列（$\lambda$ vs $\mu$）。全体の生産量 = 制約の処理能力
- 次回は、ボトルネックをどう直していくかの手順（5つの集中ステップ）

> **次回予告 (Unit 6):** ボトルネックを直す5つのステップ。

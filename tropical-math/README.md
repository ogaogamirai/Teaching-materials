# 📘 トロピカル代数とフロンティア法（電車の路線図から大学数学へ）

> **対象**: 一般社会人（学び直し・エンジニア・教養）  
> **前提**: 中学数学レベル（四則演算・不等式）  
> **構成**: 全8章 + 連動Webシミュレーター  

身近な電車の路線図（東京・神田・秋葉原・御茶ノ水）を出発点に、「なぜ最短時間は一瞬で解けるのか？（トロピカル半環・行列積）」「なぜ最長一筆書きは大難問なのか？（NP困難・フロンティア法・ZDD）」を解き明かす数学教養教材です。

---

## 📂 ファイル構成

- **`index.html`**: 教材本文（HTML版）。ブラウザで開くだけですぐにお読みいただけます。
- **`simulator.html`**: 連動Webシミュレーター（実験室）。ブラウザ上でトロピカル行列積やフロンティア法のコマ送りを体験できます。
- **`textbook.md`**: 教材本文の Markdown 正本。
- **`build_html.py`**: `textbook.md` から `index.html` を自動生成するビルドスクリプト。
- **`vendor/katex/`**: オフライン数式レンダリング用の KaTeX ライブラリ。

---

## 🛠️ ビルド方法

Markdown 正本（`textbook.md`）を編集した後、以下のコマンドで `index.html` を再生成できます：

```bash
python build_html.py
```

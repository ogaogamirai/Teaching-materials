# EX5 — 解答・解説（残業が減らない／成功の負担）

> **前提:** この演習の狙いは「成果を上げると仕事が増える」という『成功の逆効果』を、正のループ（悪循環）で見る SD と、対立（成果 vs 健康）を解く TOC の両方を使うこと。

---

## 1. 問題（UDE）の整理

- UDE1: 残業時間が減らない
- UDE2: 任される仕事が増え続ける
- UDE3: 疲れがたまる
- UDE4: 品質・健康に不安がある

## 2. SD の切り口（成功の逆効果のループ）

```
成果を上げる
   ▼
「できる人」と評価される
   ▼
さらに難しい仕事が任される
   ▼
仕事が増える → 残業して何とかこなす
   ▼
残業で成果を上げる
   ▼
（最初に戻る＝正のループが悪い方向に働く）
```

これは**正のループが悪い方向に働いた悪循環**。「成果→評価→仕事増→残業→成果」の輪。頑張れば頑張るほど、負担が増える。これが **『成功の逆効果』**。

**参照モード（Unit 9）:** このままだと、疲労（ストック）がたまり続け、いずれ品質・健康が大きく崩れる。

**介入点（SD）:**
- 正の悪循環を**切る**: 「残業で成果を上げる」をやめる（残業を成果の条件にしない）
- ストックの**出フロー**: 疲労（ストック）を回復させる時間を確保する
- 遅れ（Unit 4）: 疲労の影響（健康）は後から出る。**早めに手を打つ**

## 3. TOC の切り口（対立の解体）

**蒸発する雲（対立）:**

```
[目的C] 長期的に成果を上げ続けたい（成長し続けたい）
   ／                              ＼
[要求A] 今の仕事をやり遂げたい     [要求B] 健康・家族を守りたい
   │                                  │
[行動A] 残業して全部やる        ←→  [行動B] 残業をやめて定時で帰る
```

**共通の目的C:** 実は「長期的に成果を上げ続ける」で一致している。短期的な成果（残業）は、長期的には成果を壊す。

**対立の前提（思い込み）:**
- 「この仕事は、私しかできない」
- 「残業しないと、成果を出せない・評価されない」

**Injection（前提を外す）:**
- 「私しかできない」を外す: 仕事の分担・引き継ぎ・仕組み化（属人化を防ぐ）
- 「残業しないと評価されない」を外す: 成果の測り方を「時間」でなく「成果の質」にする
- これで「仕事をやり遂げる」と「健康を守る」の対立が消え、**両方かなえられる仕組み**になる

**根本原因（CRT・Unit 7）:** 「成果＝残業時間」という評価の仕組み（または属人化）。

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 「成果→仕事増→残業」の悪循環と、疲労の蓄積 | なぜ頑張るほど負担が増えるか。ループを切る |
| TOC | 対立（成果 vs 健康）と、その前提（属人化・時間評価） | 何が対立を作っているか。前提を外して両立 |

- SD: 「成功の逆効果。残業で成果を上げるループを切る」
- TOC: 「『私しかできない』『残業＝評価』の前提を外すと、成果と健康は両立できる」

## 5. Teach-Back 用の要点

- 残業が減らないのは「努力が足りない」からではなく、**成功の逆効果（成果→仕事増→残業）という構造**
- 対立は「成果」と「健康」だが、共通の目的は「長期的に成果を上げ続ける」
- 解決は「残業を我慢する」ではなく「**属人化・時間評価という前提を外す仕組み**」

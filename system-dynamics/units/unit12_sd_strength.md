# Unit 12 — SD の強みが発揮される大規模問題：巨大で複雑な問題を「構造」で読む

> **対象:** 一般社会人〜大学学部生レベル（中2は興味があれば読んでよい）
> **ゴール（L3 Teach-Back）:** 身近な問題では見えなかった SD の真価（複雑系の構造理解）を、4つの実例で体験し、「なぜこれが SD にしかできないか」を説明できる
> **所要目安:** 各 SDX を 15〜20分 × 4
> **位置づけ:** 任意の番外編。Unit 11（対比と抽象化）の後に読むのがおすすめ

---

## 1. Hook — 「身近な問題」では測れなかった SD の実力

これまでの演習（Unit 1〜11）は、どれも「身近な問題」でした。

- お風呂の水位・テスト勉強・部活・会議・残業・値下げ…

これらの問題では、**「どこを直すか」が比較的はっきり**していて、TOC や OR（最適化）の切り口が強く見えました。SD は「構造の理解」に回ることが多かったと思います。

でも、世の中にはこんな問題があります。

> **気候変動。感染症のパンデミック。都市の成長と衰退。企業の興亡。**

これらは**複雑で、時間がかかり、要素が絡み合い、単純な最適解が存在しません。** こういう問題こそ、SD の出番です。このUnitでは、SD が「どんな問題を得意とするか」「何をどう見せてくれるか」を実例で体験します。

## 2. SD が得意とする問題の特徴（Value）

SD が真価を発揮する問題には、共通の特徴があります。

| 特徴 | 意味 | 例 |
|---|---|---|
| **複雑** | 要素がたくさん絡み合っている | 気候・経済・社会 |
| **時間が長い** | 効果が何年・何十年後に出る | 気温上昇・少子化 |
| **循環** | 原因と結果が相互に作用する | 環境と経済 |
| **非線形** | 2倍にすれば2倍、とは限らない | 感染症の爆発的流行 |
| **最適解がない** | 正しい答えが1つに定まらない | 政策・戦略 |

> **SD は「解を出す」道具ではなく「構造を理解する」道具。** だからこそ、最適解のない複雑な問題で本領を発揮します。

## 3. OR（解く）と SD（理解する）の使い分け（Reveal）

| | OR（オペレーションリサーチ） | SD（システムダイナミクス） |
|---|---|---|
| 問い | 最適な解は何か | なぜそうなるのか |
| 得意 | 境界が明確・解が存在する問題 | 複雑・循環・時間が長い問題 |
| 例 | 生産計画・輸送・在庫・スケジュール | 気候・感染症・都市・経営戦略 |
| 答え | 数値（この計画が最適） | 構造（このループが原因） |

**使い分けのコツ:**

```
問題の境界が明確で、最適解が求められる → OR
問題が複雑で、原因と結果が循環している → SD
```

**ただし、これは「どちらか」ではありません。** 複雑な問題でも、その中の一部分（例: 在庫管理）は OR で解ける。**全体を SD で理解し、部分を OR で解く**のが本格的な使い方です。

# SDX1 — 気候変動：温室効果ガスと気温の「増幅ループ」

## 1. 事例の概要

地球の平均気温が上がり続けています。その原因とされるのが「温室効果ガス（CO₂など）」の増加です。

```
工場・車がCO₂を出す → 大気中のCO₂が増える
   ▼
温室効果が強まる → 気温が上がる
   ▼
氷が溶ける・海が膨張する → さらに影響が広がる
```

## 2. SD の構造（読み取り方）

### ストックとフロー

```
CO₂の排出（フローIN）──▶ [大気中のCO₂（ストック）] ◀── 吸収（フローOUT）
                             ↑ ここが「たまっている」
```

- **ストック**: 大気中の CO₂（たまっている量）
- **フローIN**: 工場・車・森林破壊による排出
- **フローOUT**: 森林・海洋による吸収

**読み取り方のポイント:** 問題は「排出量」だけでなく「**たまっている CO₂の量（ストック）**」です。排出を少し減らしても、ストック（たまっている量）は減りません。**減るには時間がかかる**。

### フィードバックループ

**正のループ（増幅）:**

```
気温が上がる
   ▼
氷が溶ける（白い氷が減る → 太陽光を反射しなくなる）
   ▼
地球がより熱を吸収する
   ▼
さらに気温が上がる ←（正のループ・自己増幅）
```

これは「**暴走の可能性**」を示す構造。気温上昇が気温上昇を呼ぶ、雪だるま式の危険なループです。

## 3. 時間の遅れ（意味）

SD が見せる重要なことのひとつが「時間の遅れ」です。

```
CO₂を排出（今） →（数十年の遅れ）→ 気温上昇が顕在化
```

**今日排出した CO₂ の影響は、数十年後に出ます。** だから「今、まだ大丈夫」と錯覚する。SD はこの**遅れ**を見える化します。

## 4. 意義（なぜ SD で見る価値があるか）

- **OR（最適化）では扱えない**: 気候の「最適なCO₂排出量」を数値で出しても、現実の政策はそれだけで決まりません（政治的・経済的・倫理的要素が絡む）
- **SD は「構造」を示す**: 「なぜ気温上昇が止まらないのか」「どのループを切れば止まるのか」を、誰にでも見える図で説明できる
- **政策の副反応を予見**: 「経済成長を優先」すれば CO₂ が増え、その影響が後から返ってくる（政策抵抗・Unit 9）

**SD の答え:** 「CO₂の排出（フロー）を減らす」だけでなく、**たまっている CO₂（ストック）を減らす**（吸収を増やす）ことと、**増幅ループを切る**（氷の融解・森林破壊を止める）ことが必要。

# SDX2 — 感染症の流行（SIR モデル）：なぜ爆発的に広がるのか

## 1. 事例の概要

新型の感染症が、あっという間に世界中に広がりました。最初は「数人」だったのが、数週間で「数万人」に。

```
感染者が増える → うつす人が増える → さらに感染者が増える
```

## 2. SD の構造（読み取り方）

### ストックとフロー（SIR モデルの骨格）

感染者を「たまるもの」で考えると、次の3つの「たまり」があります。

```
[S: 感受性者（かかっていない人）] ──感染──▶ [I: 感染者] ──回復──▶ [R: 回復者（免疫あり）]
```

| ストック | 意味 |
|---|---|
| S（感受性者） | まだかかっていない・うつる可能性がある人 |
| I（感染者） | 現在感染している人 |
| R（回復者） | 治って免疫を持った人（もううつさない） |

### 正のループ（爆発的拡大）

```
感染者（I）が多い
   ▼
1人がうつす相手の数が多い
   ▼
新たな感染者が増える
   ▼
感染者（I）がさらに増える ←（正のループ）
```

**これが「爆発的」に広がる理由。** 感染者が増えるほど、新たな感染者を生むスピードも上がる。**非線形**（2倍→4倍→16倍…）の増え方になります。

### 負のループ（抑える力）

```
感染者が増える
   ▼
対策（マスク・距離・ワクチン）が強まる
   ▼
感染が減る ←（負のループ・バランス）
```

さらに、**R（回復者）が増える**と、うつる相手（S）が減るので、感染は自然に収束していきます（集団免疫）。

## 3. 読み取り方のポイント

- **なぜ最初「大丈夫」に見えたか**: 感染者が少ないうちは、正のループもゆっくり。指数関数的な増加（Unit 3 発展編の $e^{rt}$）は「遅れて」爆発する
- **対策の意味**: マスク・距離・ワクチンは、正のループ（拡大）を抑える「介入点（Unit 9）」
- **時間の遅れ**: 感染から発症・報告まで遅れがある → 対策が遅れる → さらに拡大

## 4. 意義（なぜ SD で見る価値があるか）

- **OR だけでは不十分**: ワクチンを「何本配るのが最適か」は OR で解けるが、「いつ・どの対策が効くか」は、感染のダイナミクス（時間的振る舞い）を見ないと分からない
- **SD は「なぜ爆発するか」を説明**: 正のループの構造が見えると、早期対策の重要性が自明になる
- **政策の副反応を予見**: 早く開けすぎると再拡大（対策と感染のタイミングの遅れ）

**SD の答え:** 「感染者数（I のストック）」を追うだけでなく、**正のループ（拡大）をどう抑えるか**（介入点）と、**遅れ**を理解して、**早めに・十分に**対策することが鍵。

# SDX3 — 都市の成長と限界：なぜ発展が止まるのか

## 1. 事例の概要

ある都市が急速に発展しました。企業が集まり、人口が増え、活気があふれました。しかし、ある頃から成長が止まり、問題が増え始めました。

```
発展 → 人が集まる → さらに発展（正のループ）
        ↓ でも…
        インフラが限界 → 渋滞・家賃高騰・環境悪化
```

## 2. SD の構造（読み取り方）

### 正のループ（成長）

```
都市が魅力的 → 企業・人が集まる → 経済が発展 → さらに魅力的に
```

これは **Unit 3 で学んだ成長の正のループ**。最初は順調に伸びます。

### 負のループ（限界 = 抑制）

```
人口が増える
   ▼
交通が渋滞する・家賃が高騰する・環境が悪化する
   ▼
都市の「住みやすさ」が下がる
   ▼
人が離れる・企業が移転する → 成長が止まる
```

これは **Unit 3 発展編で学んだ『成長の限界』**。正のループ（伸びる）と、負のループ（抑える）の**ぶつかり合い**です。

### 時間の遅れ（厄介な点）

```
人口が増える（今） →（数年〜十数年の遅れ）→ インフラ不足が顕在化
```

**インフラ整備は後からしか追いつきません。** 「今は大丈夫」と感じていても、実は限界に近づいている。SD はこの遅れを見える化します。

## 3. 読み取り方のポイント

- 成長が止まるのは「努力が足りない」のではなく「**構造（制約）**」が原因（Unit 5 のボトルネックと同じ考え方）
- **ボトルネック**: 都市の成長を止めているのは「インフラ・住居・環境」のどれ？
- **介入点**: 負のループ（住みにくさ）を緩和する（交通整備・住居供給・環境対策）

## 4. 意義（なぜ SD で見る価値があるか）

- **OR の限界**: 「道路を何本作れば最適か」は OR で解ける。しかし「都市がなぜ衰退するか」という構造全体は、ループで見る必要がある
- **SD は「都市の未来」を予測する**: 人口・インフラ・環境のループを組むと、**「このままだとどうなる」**（Unit 9 の参照モード）を描ける
- **成長の限界の一般性**: 同じ構造が「都市」「企業」「生物の増殖」などに共通して現れる（抽象化・Unit 11）

**SD の答え:** 都市の発展は「正のループ（成長）× 負のループ（限界）」の構造。成長を持続するには、**限界（インフラ・環境）を先回りして直す**こと。放置すると、成長は頭打ちどころか衰退に転じる。

# SDX4 — 経営戦略：規模の経済と衰退の罠

## 1. 事例の概要

ある会社が事業を拡大しています。規模が大きくなれば、コストが下がり、さらに市場を取れる。しかし、ある時点から「大きくなるほど動きが鈍る」現象が起き始めました。

```
規模拡大 → コスト低下 → 競争力向上 → さらに拡大（正のループ）
        ↓ でも…
        組織が複雑化 → 意思決定が遅い → 衰退の兆し
```

## 2. SD の構造（読み取り方）

### 正のループ（規模の経済）

```
生産量が増える
   ▼
1個あたりのコストが下がる（規模の経済）
   ▼
価格競争力が上がる → シェアが増える
   ▼
さらに生産量が増える ←（正のループ）
```

これは**「勝ち続ける」構造**。大きな会社がさらに強くなる理由です。

### 負のループ（規模の不経済・組織の鈍化）

```
組織が大きくなる
   ▼
部門が増え、意思決定の経路が長くなる
   ▼
決断が遅くなる・現場の声が届かない
   ▼
市場の変化に乗り遅れる → 競争力が落ちる
   ▼
（成長が止まる・衰退する）
```

これは **『成功の逆効果』**（Unit 3・EX5 と同じ構造）。「成功（規模拡大）」が「次の成功を妨げる（組織の鈍化）」を生みます。

### 政策抵抗（厄介な点）

「リストラして効率化しよう」「上場して資本を集めよう」という対策は、**短期的には効くが、組織の鈍化（負のループ）を根本からは直さない**。対策が既存ループに吸収される（Unit 9 の政策抵抗）。

## 3. 読み取り方のポイント

- 企業の成長は「正のループ（規模の経済）× 負のループ（組織の鈍化）」の綱引き
- **ボトルネック**: 今、成長を止めているのは「コスト」か「組織の意思決定」か「市場の変化」か
- **介入点**: 組織の鈍化ループを切る（意思決定を現場に委ねる・部門間の壁をなくす）

## 4. 意義（なぜ SD で見る価値があるか）

- **経営は「最適解」がない**: 「何%成長するのが最適」と数値で出しても、実際の経営は競争・組織・文化が絡み合う
- **SD は経営の「構造」を診断する**: 「なぜ大きくなると鈍るのか」「どのループが今効いているか」を見える化する（フォレスターが SD を生んだのは、もともと経営分析のため）
- **企業の興亡は繰り返す**: この構造は、多くの企業で何度も繰り返される（抽象化・型の発見）

**SD の答え:** 経営は「規模の経済（正）と組織の鈍化（負）の綱引き」。成長を持続するには、**正のループだけを追わず、負のループ（組織の鈍化）を先回りして直す**ことが必要。大きくなるほど、それを防ぐ仕組みが要る。

# まとめ：SD の強みが4つの実例で見えたもの

| SDX | テーマ | 中心の構造 | SD が示したこと |
|---|---|---|---|
| 1 | 気候変動 | 正のループ（増幅）・時間の遅れ | 排出量より「たまっている量」。増幅ループを切る |
| 2 | 感染症 | 正のループ（爆発）・ストック（SIR） | なぜ爆発するか。介入点と遅れ |
| 3 | 都市 | 成長の限界（正×負） | 成長が止まるのは構造（制約）。先回り |
| 4 | 経営 | 規模の経済 × 組織の鈍化 | 大きくなるほど鈍る。負のループを直す |

## 共通して見えた「SD ならでは」の強み

1. **時間の遅れを見える化する** — 今の問題の原因が、何年・何十年前にあるか
2. **循環する構造を見える化する** — 「AだからB、BだからA」の相互依存
3. **非線形（爆発・暴走）を説明できる** — 2倍→4倍→16倍の世界
4. **政策の副反応（政策抵抗）を予見する** — 対策が構造に吸収される
5. **最適解のない問題でも「構造」を示せる** — OR が得意としない領域

> **OR は「この解が最適」と答え、SD は「この構造が原因」と答える。**
> 複雑で大きな問題には、この2つを合わせて使うのが本格的。SD を知ることは、その土台を手に入れることです。

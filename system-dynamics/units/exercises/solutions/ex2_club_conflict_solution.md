# EX2 — 解答・解説（部活の先輩後輩の対立）

> **前提:** この演習の狙いは「対立に見える問題を、蒸発する雲で構造化して解く」こと。SD のループと TOC の対立の2つを見る。

---

## 1. 問題（UDE）の整理

- UDE1: 先輩と後輩の会話がなくなった
- UDE2: 練習の雰囲気が悪い
- UDE3: チームの実力が伸びない

## 2. SD の切り口（ループで見る）

対立の悪循環をループ図で描く。

```
Bさん（先輩）が注意する
   ▼
Cさん（後輩）が反発する
   ▼
Bさんは「言うことを聞かない」と思い、さらに強く注意する
   ▼
Cさんは「先輩は古い」と思い、さらに反発する
   ▼
（最初に戻る＝悪循環）
```

これは**正のループが悪い方向に働いた悪循環**（エスカレーション）です。お互いの行動が相手の行動を強め合い、どんどん悪化します。

**介入点（SD）:**
- 悪循環ループを**切る**: どちらかが「反応しない」を選ぶ（返しをやめる）
- 遅れ（Unit 4）: 一度壊れた関係は、すぐには戻らない。**待つ設計**が必要

## 3. TOC の切り口（蒸発する雲）

対立の構造を「蒸発する雲」で描く。

```
        [目的C] チームを強くしたい（良いチームを作りたい）
        ／                              ＼
  [要求A] 規律を守ってほしい          [要求B] 自分の考えで工夫したい
     │                                    │
  [行動A] 先輩の指示に従わせる    ←→   [行動B] 自分の練習メニューを試す
```

**共通の目的C:** 実は2人とも「チームを強くしたい」で一致している。

**対立の前提（思い込み）:**
- Bさん側: 「後輩が自分で工夫する ＝ 規律を軽んじている」
- Cさん側: 「先輩の指示に従う ＝ 自分の考えを捨てる」

**Injection（前提を外す）:**
- 「規律を守ること」と「自分で工夫すること」は**両立できる**仕組みを作る
  - 例: 「基本の形（規律）は守る。工夫は基本の上で、練習後の自由時間に試す」
  - 例: 先輩が後輩の工夫を「提案」として聞く時間を作る
- これで「規律」と「工夫」の対立が消え、どちらもかなえられる

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 悪循環のループと、その悪化のスピード | なぜ止まらず悪化するか。ループを切る |
| TOC | 対立の構造と共通の目的 | なぜ対立しているか。前提を外して両立 |

- SD: 「お互いが強め合って悪循環になっている」
- TOC: 「実は目的は同じ（チームを強くしたい）。前提の思い込みが対立を作っていた」

## 5. Teach-Back 用の要点

- 対立は「価値観の違い」だけでなく、**悪循環のループ**としても見える
- 蒸発する雲で共通の目的（C）を見つけると、対立が「どっちが正しいか」から「どう両立するか」に変わる
- 解決は「どちらかが折れる」ではなく「**前提を外して両方かなえる仕組み**」

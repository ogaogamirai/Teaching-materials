# Unit 7 — 演習A（基本編）: CRTを作る — 現状問題ツリーで根本原因を見つける

> **対象:** 中学2年生〜一般社会人
> **ゴール（L3 Teach-Back）:** 問題（UDE）を因果でつなぎ、根本原因（Core Constraint）を1つ特定できる
> **所要目安:** 20〜30分（例題つき）
> **準備:** 演習カード `exercises/ex1_getting_up.md`（例題）を手元に

---

## 1. Hook — 「問題の原因」は1つに絞れる？

「朝起きられない」という問題があったとします。原因はなんでしょう？

- 夜更かし？ 朝ごはんを食べないから？ 授業がつまらないから？ スマホ？ 疲れ？

**全部それっぽいですよね。** でも、全部を直すのは大変。そこでTOCの考え方です。

> **「全部の症状（UDE）を説明できる、ただ1つの根本原因」に絞り込む。**

これができれば、直す場所が1つに決まります。このUnitで作る「現状問題ツリー（CRT）」は、そのための道具です。

## 2. CRTとは（Value→Purpose→Meaning）

### Value（価値）
- 「原因がいくつもあるように見える」問題も、**矢印でつなぐと1つの根本原因に収束する**ことが多い
- 根本原因を直せば、たくさんの症状がまとめて良くなる

### Purpose（目的）
問題（UDE）を因果関係でつないだ「木のような図」を作る。それがCRT。

### Meaning（意味）

| 用語 | 意味 |
|---|---|
| **UDE**（Undesirable Effect） | 現状の不都合な事象（問題の症状） |
| **CRT**（Current Reality Tree） | 現状問題ツリー。UDEを「なぜなら」でつないだ図 |
| **Core Constraint** | 根本原因。矢印が一番多く「原因」として出ているノード |

## 3. CRTの作り方（4ステップ）

```
Step1 問題（UDE）を列挙する
   ↓ 原因や解決策を混ぜず、「観測できる症状」を1項目1文で
Step2 因果でつなぐ
   ↓ 「Aが起きる、なぜならBだから」の矢印で結ぶ
Step3 輪（ループ）を探す
   ↓ 悪循環（負のループ）があれば、それが「現状が続く理由」
Step4 根本原因を特定する
   ↓ 「原因」として矢印が一番多く出ているノードが Core Constraint
```

## 4. 演習フレーム（Unit 7〜9 共通）

各演習カードは次の共通フレームで進める。

```
Step1 題材を選ぶ（選択式）
Step2 問題（UDE）を列挙する
Step3 因果でつなぐ（CRT / ループ図）
Step4 根本原因（Core Constraint）を特定する
Step5 対立を解体する（蒸発する雲）※Unit 8
Step6 解消策（Injection）を設計する ※Unit 8
Step7 新たな問題が起きないか確認する（FRT）※Unit 8
Step8 Teach-Back（自分の選んだ題材で説明）
```

このUnitでは **Step1〜4（CRTまで）** を行う。Step5〜8 は Unit 8 で。

## 5. 例題（EX1: 朝起きられない悪循環）— 解答つき

演習カード `exercises/ex1_getting_up.md` を使って、CRTの作り方を追う。

### Step2: UDEを列挙

| # | UDE（観測できる症状） |
|---|---|
| UDE1 | 朝、起きられない |
| UDE2 | 夜更かししてしまう |
| UDE3 | 朝ごはんを食べられない |
| UDE4 | 授業中に眠くなる |
| UDE5 | 家に帰ると疲れている |

### Step3: 因果でつなぐ

```
[夜更かししてしまう] ←── [スマホを触る]
       │
       ▼
[朝、起きられない]
       │
       ▼
[朝ごはんを食べられない]
       │
       ▼
[授業中に眠くなる] ←── [疲れがたまる]
       │
       ▼
[家に帰ると疲れている]
       │
       ▼
[夜更かししてしまう] ←──（またスマホを触る）
```

### Step4: 根本原因（Core Constraint）の特定

「原因」として矢印が一番多く出ているのは **「夜更かししてしまう」**。

- 「朝起きられない」は結果
- 「朝ごはんを食べられない」「眠くなる」も結果
- 全部を説明する原因は「夜更かし」に集約される

> **根本原因 = 夜更かし（寝る時間が遅い）**

さらに、このCRTは**輪（ループ）**になっている。「夜更かし→朝起きられない→疲れる→また夜更かし」という**悪循環（負のループ）**。ここに時間の遅れ（Unit 4）も絡んでいる（寝る時間の影響が「朝の起きやすさ」に現れるまで時間がかかる）。

**結論:** 「スマホをやめる」だけでも「朝ごはんを食べる」だけでも、対策がバラバラでは効果が薄い。**根本原因（夜更かし）を直す**ことで、複数の症状がまとめて改善し始める。

## 6. Check — 確かめてみよう

1. UDEとは何？
2. Core Constraint（根本原因）は、図のどこを見れば分かる？
3. CRTが輪（ループ）になっていたら、それは何を表す？

> **答え（下を見る前に自分で）:**
> 1. 現状の不都合な事象（問題の症状）　2. 「原因」として矢印が一番多く出ているノード　3. 悪循環（現状が続く理由・負のループ）

## 7. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「原因を全部直すのが大事」 | 根本原因1つを直すと、複数の症状がまとめて良くなる。モグラ叩きは非効率 |
| 「解決策から考える」 | 先に「原因（構造）」を見る。解決策は Unit 8（Injection）で |
| 「原因と症状が混ざってOK」 | UDEは「観測できる症状」だけを書く。原因・解決策を混ぜない |

## 8. やってみよう — 選択式演習

CRTの作り方が分かったら、自分の選んだ演習カードで練習する。

- **EX2**（部活の先輩後輩の対立）
- **EX3**（クラスの係活動が回らない）
- **EX7**（SNS依存・情報過多）
- 社会人の人は **EX4〜6・EX9** を選んでよい（Unit 9 で深く扱う）

**ここでやること:** Step1〜4（UDE列挙→因果→根本原因特定）まで。

> **やってみよう:** 選んだ題材でCRTを描き、根本原因を1つに絞ってみよう。

## 9. Teach-Back — 素人に説明しよう

1. **何の話か:** 「問題の原因は1つに絞れる」という話
2. **部品は何か:** UDE（症状）・矢印（因果）・Core Constraint（根本原因）
3. **どう繋がるか:** 症状を「なぜなら」でつなぐと、矢印が一番出る根本原因に収束する
4. **図はどこを見ればいいか:** 矢印が一番多く「原因」として出ているところ
5. **よくある誤解:** 原因を全部直すのが大事、ではない
6. **素人への一言:** 「朝起きられないのは夜更かしが根本原因だよ。朝ごはんだけ直しても、夜更かしなら治らない」

---

## まとめ（Takeaway）

- **UDE** = 観測できる症状。原因・解決策を混ぜない
- **CRT** = UDEを「なぜなら」でつないだ図
- **根本原因（Core Constraint）** = 矢印が一番多く出ているノード
- CRTが輪（ループ）なら、それは悪循環（現状が続く理由）
- 根本原因を1つ直すと、複数の症状がまとめて良くなる
- 次回は「根本原因をどう解消するか」（蒸発する雲・Injection）

> **次回予告 (Unit 8):** 対立を解体し、根本原因を解消する「蒸発する雲」。

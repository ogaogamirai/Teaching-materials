# 学習設計 v0.1

## 到達目標

- 暗号化、復号、鍵、攻撃者の役割を説明できる。
- `mod` の計算を使って、有限体を小さな数の世界として扱える。
- RSAの「掛け算は簡単、素因数分解は難しい」という非対称性を説明できる。
- 楕円曲線上の点の足し算とスカラー倍を図で追跡できる。
- ECDLPを「公開された点から秘密の回数を逆算する難しい問題」と説明できる。
- ECCは通信全体ではなく、鍵交換や署名の部品だと理解できる。
- PQCが別の数学的問題を安全性の土台にすることを説明できる。

## 編集原則

1. 先に問いを置き、用語を後から導入する。
2. 実数上の楕円曲線と有限体上の点集合を別章・別画面にする。
3. 小さな例では逆算できることを隠さず、実用サイズと分ける。
4. 数式、コード、図が同じ定義を参照する。
5. 2Dは因果・手順・比較、3Dは点・曲線・視点変更に使う。
6. 各章に「操作 → 観察 → 式の意味 → 次の問い」を置く。
7. 新しい概念は、最初に一言で定義し、その後に「材料をどう選び、どう作るか」を示す。
8. 小さな例を実際に計算し、逆算・探索・変化を体感してから一般化する。

## 章の流れ

| 章 | 問い | 数学 | 表現 |
|---|---|---|---|
| 00 | 暗号の計算に何が必要か | 素数・GCD・逆数・座標・mod | 数学の道具箱 |
| 01 | 秘密をどう守るか | なし | 2D通信図 |
| 02 | 余りの世界で計算できるか | mod | 時計・有限体 |
| 03 | 秘密を先に渡さず通信できるか | 素数・GCD（最大公約数） | RSA |
| 04 | 曲線の上で足し算できるか | 座標・曲線 | 2D曲線 |
| 05 | ECCは何を難しくしているか | 点群・離散対数 | 3D/点群 |
| 06 | 実際の通信ではどう使うか | 役割分担 | HTTPS図 |
| 07 | 量子計算機にはどう備えるか | 発展 | PQC地図 |
| 08 | 通信を支える短い言葉を整理する | ハッシュ・署名・証明書 | 役割図 |
| 09 | 方式ごとに何が暗号になるか | 文字・数値・点・バイト列 | 実演ラボ |

## 未解決の編集課題

- 中学2年生に対する「群」「有限体」の厳密さの境界を決める。
- RSAとECCの安全性・鍵長比較は、現行標準の条件付き数値で再確認する。
- 3D Commonsの楕円曲線モデルを、実数曲線・有限体・スカラー倍の3段に分ける。
- JIPDECの古い資料は歴史的説明に限定し、現行の推奨・非推奨は最新の標準資料で補う。
- ハッシュ、署名、証明書、鍵交換を本編から外さず、短い補助章で先に意味を定着させる。

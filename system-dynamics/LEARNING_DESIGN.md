## 0. 一文定義

**「なぜそうなるのか（構造）」と「どこを直すか（制約）」を、ぐるぐる回る関係（フィードバック）と流れ（ストック＆フロー）で捉え、Teach-Back で人に説明できる状態をゴールにする、中学2年生から一般社会人まで段階的に読み進められるシステム思考教材。最終到達点は大学学部生レベルの理解。**

## 1. 設計原則（非交渉）

| ID | 原則 | 意味 | 禁止 |
|----|------|------|------|
| P1 | **動機主導** | 身近な例（貯金・SNS・風邪）から入る。「これが分かると何が良いか」を最初に | 目的不明の概念積み上げ |
| P2 | **Value→Purpose→Meaning** | 価値（なぜ）→ 目的（何のため）→ 意味（どう機能する）の順 | 定義・用語の羅列から始める |
| P3 | **Teach-Back が習熟の定義** | 「素人に説明できる」が完了条件 | 選択問題の正答だけを完了にする |
| P4 | **同名異義語を最初に区別** | 「ストック」「システム」「ダイナミクス」等の言葉の違いを最初に丁寧に | 混同したまま進める |
| P5 | **具体→抽象** | 具体例で掴んでから、後半（Unit 7–8）で抽象化・メタ化 | 抽象概念から始める |
| P6 | **学ぶ→やってみる→例で定着→確認→教え返し** | 各ユニットを5段で構成 | 確認ゲートだけにする |
| P7 | **二段構え（レイヤー型）** | 各ユニットを「基本編（中2でも分かる）→ 発展編（大学レベル）」の2層で構成。1冊を読み進めるだけで中2→大学学部生レベルへ | 対象を別々の教材に分断する |
| P8 | **基礎は妥協しない** | 基本編を丁寧に書き、発展編は基本編の「意味」を深める形にする（fourier の3層構造・土台先行と同じ思想） | 発展編の見栄え優先で基礎を手抜きする |
| P9 | **数式は表示し説明する** | 使う数式は必ず表示し、記号の意味・読み方・言葉との対応を説明する。数式は「言葉のルールを短く正確にしたもの」と位置づける | 数式を出しっぱなしにする・暗記させる |
| P10 | **数理前提は理論ルートで補う** | 発展編の数式の前提は math-bridge で学ぶ。本編には「どこまで必要か」を補記する | 発展編で未習の数理を無前提に使う |

## 2. 対象と到達像

- **主:** 中学2年生〜一般社会人
- **到達像:** 中学2年生でも、最初から順に読み進めることで**大学学部生レベルの理解**まで到達できる
- **到達像ルーブリック**（fourier L0–L4 を適用）

| レベル | 名前 | 判定 |
|--------|------|------|
| L0 | 体験 | 身近な例で「何が起きているか」を日常語で言える |
| L1 | 構造 | ストック・フロー・フィードバック・ボトルネックの役割を指差し説明できる |
| L2 | 記号 | 因果ループ図・ストックフロー図の要素を「なぜ」で説明できる |
| L3 | **Teach-Back（目標）** | 素人役に数分で教え、典型誤解を自分で訂正できる |
| L4 | 転移（任意） | 学んだ型を新しい領域（学校行事・スポーツ・社会問題等）へ応用できる |
| L5 | **大学学部生レベル** | 数理的表現（微分方程式・シミュレーション）で構造を記述・分析できる |

**各ユニットの基本編完了条件 = L3。発展編で L5 を目指す。**

### レイヤー構造（案A）

```
【発展編（大学レベル）】 数理的表現・シミュレーション・厳密な記述   ← L5
         ▲ 意味を深める（同一テーマのまま、層を上げる）
【基本編（中2〜）】      身近な例・直感・図・言葉での説明            ← L0–L3
```

- 同じユニット内で基本編 → 発展編の順に読み進める（別教材に分けない）
- 発展編は基本編の「意味」を数理・構造で深める

### 理論ルート（Math Bridge）— 数理前提の補助Unit

発展編（大学レベル）で使う数理表現は、**「理論ルート」という補助Unit群**で必要な前提を学ぶ。

```
基本編（中2〜） ──→ 発展編（大学レベル）
      │                    ▲
      └──→ 【理論ルート / math-bridge/】 ─┘
          （発展編に進む前に必要な数学の前提だけを学ぶ）
```

| ルール | 内容 |
|--------|------|
| 独立ルート | 補助Unitは `math-bridge/` に置き、本編ユニットとは分ける |
| 必要な人だけ | 既に数学を学んだ人はスキップ可。中2は発展編前に挟む（fourier の「三角比ミニ」と同じ発想） |
| **どこまで必要かを本編に明記** | 各ユニットの発展編に「必要な前提: math-bridge のB2まで」等を補記する |
| 数式は説明つきで | 使う数式はすべて表示し、記号の意味・読み方を説明する（P9） |
| 最小の橋 | 発展編に必要な「最小限の数学」だけを用意する。網羅的な数学教科書にはしない |

**理論ルートの目次（案・随時更新）:**

```
math-bridge/
  B1 変化率と割合（中1・中2既習の復習・変化の割合）
  B2 関数とグラフ（y=ax、変化の割合の意味）
  B3 「変化の割合」→「瞬間の変化率」の直感（速さの例）
  B4 微分の意味（「変化する速さ」を測る道具。計算は最小限）
  B5 微分方程式の第一歩（d(ストック)/dt = 入り − 出）
  B6 指数成長・減衰と e・ln（Unit 3発展編の前提）
  ※ 以降はユニット進行に応じて追加
```

| 補助Unit | どのユニット発展編の前提になるか |
|----------|--------------------------------|
| B1–B3 | Unit 2（ストックとフロー）発展編 |
| B4–B5 | Unit 2 発展編（微分方程式） |
| B6 | Unit 3（フィードバックループ）発展編 |

## 3. ユニットの標準構成（各ユニット共通・基本編/発展編）

```
[Hook] 身近な例の体験・問いかけ（「これ、どうしてこうなるの？」）
   ↓
───【基本編（中2〜・L0–L3）】────────────────────────
[Reveal] 短い説明（Value→Purpose→Meaning の順・120字×3程度）
[Interact] やってみる（図を書く・並べる・予測する）
[Check] 確認（選択・予測・対応づけ。数式自由入力は使わない）
[Teach-Back] 素人に説明する（テンプレ: 何の話→部品→どう繋がる→例→よくある誤解）
───【発展編（大学レベル・L4–L5）】──────────────────
[前提] 「必要な前提: math-bridge のどこまで」を明記（中2はここで挟む）
[Deepen] 基本編の「意味」を数理的表現・シミュレーションで深める
[Extend] 転移・応用（新しい領域へ）
[Check-L5] 数理表現・モデル分析の確認
```

## 4.5. 演習の設計（Unit 7–9：選択式応用演習・3区分）

演習を「基本編（中2向け）」「社会人向け（任意）」に **Unit を分けて** 設計する。
解説・図が増えるにつれ、各ユニットを独立して育成・保守できるようにするため。

### 3区分の構成

| Unit | 区分 | 対象 | 題材 | 役割 |
|------|------|------|------|------|
| **Unit 7** | 演習A（基本編） | 中2向け | EX1〜3, EX7 | CRT を作る。例題（EX1）は解答つき |
| **Unit 8** | 演習B（基本編） | 中2向け | 上記の続き | 蒸発する雲・Injection で解消する |
| **Unit 9** | 演習C（社会人向け・任意） | 社会人向け | EX4〜6, EX9, EX10 | CRT+Injection を実務問題へ応用 |

- **中2の標準ルート**: Unit 7 → 8 → 10（Unit 9 はスキップ可）
- **社会人の標準ルート**: Unit 7 はサッと流し、Unit 9 を中心 → 10

### 演習の共通フレーム（Unit 7・8・9 共通）

```
[演習の共通フレーム]
   Step1 題材を選ぶ（選択式）
   Step2 問題（UDE）を列挙する
   Step3 因果でつなぐ（CRT / ループ図）
   Step4 根本原因（Core Constraint）を特定する
   Step5 対立を解体する（蒸発する雲）※Unit 8・9
   Step6 解消策（Injection）を設計する ※Unit 8・9
   Step7 新たな問題が起きないか確認する（FRT）※Unit 8・9
   Step8 Teach-Back（自分の選んだ題材で説明）
```

### 演習の題材（選択式・複数角度）

| # | 対象 | 角度 | 題材例 | 使う要素 | 配置 |
|---|------|------|--------|----------|------|
| EX1 | 中2 | 生活系 | 朝起きられない悪循環 | 負のループ・遅れ | Unit 7 例題（解答つき） |
| EX2 | 中2 | 人間関係 | 部活の先輩後輩の対立 | 蒸発する雲・対立 | Unit 7-8 |
| EX3 | 中2 | 学校運営 | クラスの係活動が回らない | ボトルネック・負のループ | Unit 7-8 |
| EX4 | 社会人 | チーム・仕事 | 会議が多すぎて仕事が進まない | ボトルネック・時間の遅れ | Unit 9 |
| EX5 | 社会人 | 組織 | 残業が減らない（成功の負担） | 負のループ・成功の逆効果 | Unit 9 |
| EX6 | 社会人 | ビジネス | 売上が伸びない（成長の限界） | 正のループ×制約（Unit 3・5） | Unit 9 |
| EX7 | 共通 | 社会問題 | SNS依存・情報過多 | 正のループ・遅れ | Unit 7-8 |
| EX8 | 共通 | 自由テーマ | 自分で選んで1本通し | 全部 | Unit 10 直前 |
| EX9 | 社会人 | ビジネス（価格戦略） | 値下げの罠：売上は伸びたのに利益が減った | 正×負のループ・ストック（利益） | Unit 9 |
| EX10 | 社会人 | ビジネス×TOC | ボトルネックと価格：どの製品を優先する？ | スループット会計・制約 | Unit 9 |

### 選択の考え方

- 学習者は「自分の身近さ」と「やってみたい」で選ぶ
- **例題（解答つき）** は基本編の代表1つ（EX1）。他の題材は選択式で解答なし（自主演習）
- **一般社会人向け（EX4〜EX6, EX9, EX10）** を Unit 9 にまとめ、**SD・TOC の実際の効用**（価格戦略・生産性・組織課題）が伝わるようにする

### 演習のファイル構成

```
units/
  unit7_crt.md          # 演習A 共通フレーム + 例題（EX1 解答つき）
  unit8_injection.md    # 演習B 共通フレーム + 例題（EX1 の続き）
  unit9_applied.md      # 演習C（社会人向け・任意）EX4-6, EX9, EX10
  exercises/            # 選択式題材（EX1〜EX10 の個別カード）
    ex1_getting_up.md
    ex2_club_conflict.md
    ...
  exercise_cards.md     # 一覧表・選び方ガイド
```

## 5. Teach-Back 共通テンプレ（各ユニットの Check で使用）

1. **何の話か** — 1文
2. **部品は何か** — 3つまで
3. **どう繋がるか** — 因果を1本
4. **図はどこを見ればいいか** — 指差し
5. **よくある誤解** — 1つ訂正
6. **素人への一言** — 比喩1つ

# EX1 — 朝起きられない悪循環（例題・解答つき）

> 対象: 中2　使う要素: 負のループ・時間の遅れ
> 配置: Unit 7 の例題（解答つき）。Unit 8 で続き（対立の解体）を行う

---

## シチュエーション

Aさんは最近、生活がうまくいっていません。次のような状態が続いています。

- 朝、起きられない
- 起きるのが遅くて、朝ごはんを食べられない
- 授業中に眠くなる
- 最近、テストの成績が下がった
- イライラして、友達と衝突することが増えた

一見すると「朝起きられない」「成績が下がる」「友達と衝突する」は、ぜんぜん別の問題のように見えます。本当にそうでしょうか？

## 問題（UDE）の列挙

観測できる「不都合な事象」を1項目1文で書き出す。原因や解決策は混ぜない。

- UDE1: 朝、起きられない
- UDE2: 朝ごはんを食べない
- UDE3: 授業中に眠くなる
- UDE4: 成績が下がった
- UDE5: イライラして友達と衝突する

## 演習ステップ

1. **UDEを列挙する**（上記）
2. **因果でつなぐ** —「Aが起きる、なぜならBだから」の矢印で、それぞれの症状の原因を掘り下げる
3. **因果を検証する** — 矢印が本当に因果か、Unit 7 §4.5 のチェック項目で確かめる
4. **共通の原因を探す** — 複数の枝がどこで合流するか
5. **Rootを特定する** — 合流の先にある、ただ1つの根本原因はどこか

## 解答例

### Step2: それぞれの枝を掘り下げる

```
[UDE: 朝、起きられない]
   ▼ なぜなら（寝るのが遅い）
[UDE: 朝ごはんを食べない]
   ▼ なぜなら（起きるのが遅くて時間がない）
[Cause: 午前中のエネルギー不足]
```

```
[UDE: 授業中に眠くなる]
   ▼ なぜなら
[Cause: 集中力が続かない]
   ▼ なぜなら
[UDE: 成績が下がる]
```

```
[UDE: イライラする]
   ▼ なぜなら
[UDE: 友達と衝突する]
```

### Step3: 因果の検証（Unit 7 §4.5）

引いた矢印をチェック項目で検証する。

| 矢印 | 検証 | 判定 |
|---|---|---|
| 「睡眠不足」→「朝起きられない」 | 眠れなければ起きられない（3・4・7 OK） | 合格 |
| 「授業中に眠くなる」→「成績が下がる」 | 中間に「集中力が続かない」を入れて丁寧に（8の飛躍チェック） | 合格（中間ノード追加） |
| 「朝ごはんを食べない」→「眠くなる」 | **5番の危険**（実は睡眠不足が原因かも） | 修正（原因を掘り下げる） |

### Step4: 共通の原因（合流）

3つの枝をさらに辿ると、全部が同じ原因に行き着く。

> 「午前中のエネルギー不足」はなぜ？ → **睡眠不足**
> 「集中力が続かない」はなぜ？ → **睡眠不足**
> 「イライラする」はなぜ？ → **睡眠不足**

→ 3つの枝が **「睡眠不足」という1つの Cause に合流**する。

さらに「睡眠不足」はなぜ？ → **夜更かし** → なぜ？ → **寝る前にスマホを見てしまう**

### Step5: Root（根本原因）の特定

```
[UDE: 朝、起きられない] → [UDE: 朝ごはんを食べない] → [Cause: エネルギー不足] ─┐
                                                                             ├─► [睡眠不足] ◀─ [夜更かし] ◀─ [スマホ] ← Root
[UDE: 授業中に眠くなる] → [Cause: 集中力低下] → [UDE: 成績が下がる] ───────────┘
[UDE: イライラする] → [UDE: 友達と衝突する] ────────────────────────────────────┘
```

> **Root（根本原因）= 夜更かし（寝る前にスマホを見てしまう）**

### ここがCRTの良さ

「朝起きられない」「成績が下がる」「友達と衝突する」は、**見た目はバラバラの問題**。
でも因果を辿ると、**全部が1つの Root に収束**する。

だから、個別に「朝の努力」「勉強の頑張り」「友達との仲直り」と対策を5つ考えるのではなく、
**Root（夜更かし）を直せば、5つの症状がまとめて改善し始める**、と分かる。

### 悪循環の確認（補足）

「夜更かし → 朝起きられない → 疲れ → また夜更かし」という輪（悪循環）もある。
時間の遅れ（Unit 4）も絡んでいる（寝る時間の影響が「朝の起きやすさ」に現れるまで時間がかかる）。

### ここで考えること

Rootが1つに絞れたので、Unit 8 で「どう解消するか」を考える。

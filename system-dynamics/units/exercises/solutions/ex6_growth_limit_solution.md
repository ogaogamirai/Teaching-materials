# EX6 — 解答・解説（売上が伸びない／成長の限界）

> **前提:** この演習の狙いは「順調に伸びていたものが頭打ちになる」＝『成長の限界』を、正のループと負のループ（制約）で見ること。SD と TOC の両方を使う。

---

## 1. 問題（UDE）の整理

- UDE1: 売上が頭打ち
- UDE2: 満席で客が帰る
- UDE3: スタッフ不足でサービス低下
- UDE4: 口コミが悪化し始めた

## 2. SD の切り口（成長の限界）

**正のループ（Unit 3）:**

```
客が増える → 口コミが広がる → さらに客が増える
```

これは成長の正のループ。最初は順調に伸びる。

**しかし、負のループ（制約）が成長を止める:**

```
客が増える
   ▼
席が満席になる（制約）
   ▼
満席で客が帰る・待たせる
   ▼
スタッフ不足でサービスが低下
   ▼
口コミが悪化
   ▼
客が減り始める（成長が止まる）
```

これは **『成長の限界』**（Unit 3 発展編）の典型。正のループ（伸びる）と、それを抑える負のループ（制約）がぶつかっている。

**参照モード（Unit 9）:** このまま放置すると、口コミ悪化が進み、売上が**落ち始める**（頭打ちどころか下降）。

**介入点（SD）:**
- 制約の負のループを**強める・解消する**: 席数を増やす・回転率を上げる・スタッフを増やす
- 正のループを保つ: 口コミの正のループを維持する（満席にしない）

## 3. TOC の切り口（制約＝ボトルネック）

**ボトルネック（Unit 5）:** 成長を止めている制約はどこか → **席数（キャパシティ）** と **スタッフ数**。

「客が増える」こと自体は問題ではない。**キャパシティ（席・スタッフ）** が制約で、全体の売上を頭打ちにしている。

**5つの集中ステップ（Unit 6）:**
1. 見つける: 制約は「席数（キャパシティ）」
2. 活用する: 今ある席の回転率を上げる（メニューを決め打ちにする・待ち時間を減らす）
3. 従属させる: 販売数をキャパシティに合わせる（予約制にして満席を管理）
4. 強化する: 席数を増やす・スタッフを増やす
5. 繰り返す: 席を増やしたら、次の制約（スタッフ・仕入れ）を探す

**根本原因（CRT・Unit 7）:** 「成長の正のループと、キャパシティの制約がぶつかっている」こと。努力不足ではなく**構造的な制約**。

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 正のループ（成長）と負のループ（制約）のぶつかり合い。放置すると下降 | なぜ頭打ちになるか。制約のループを解消 |
| TOC | 制約（席数・スタッフ）の特定と、5ステップでの改善 | どこを直すべきか。キャパシティを強化 |

- SD: 「成長の限界。口コミの正のループが、満席の負のループで止められている」
- TOC: 「制約は席数。まず回転率を上げ（活用）、足りなければ席数を増やす（強化）」

## 5. Teach-Back 用の要点

- 売上が頭打ちになるのは「努力が足りない」のではなく、**成長の正のループと、制約の負のループのぶつかり**
- 制約（席数・スタッフ）が全体を決めている＝ボトルネック
- 解決は「客を増やす努力」だけでなく「**制約（キャパシティ）を直す**」こと。まず活用（2）、足りなければ強化（4）

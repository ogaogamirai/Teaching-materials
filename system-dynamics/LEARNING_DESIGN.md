## 0. 一文定義

**「なぜそうなるのか（構造）」と「どこを直すか（制約）」を、ぐるぐる回る関係（フィードバック）と流れ（ストック＆フロー）で捉え、Teach-Back で人に説明できる状態をゴールにする中学2年生向けシステム思考教材。**

---

## 1. 設計原則（非交渉）

| ID | 原則 | 意味 | 禁止 |
|----|------|------|------|
| P1 | **動機主導** | 身近な例（貯金・SNS・風邪）から入る。「これが分かると何が良いか」を最初に | 目的不明の概念積み上げ |
| P2 | **Value→Purpose→Meaning** | 価値（なぜ）→ 目的（何のため）→ 意味（どう機能する）の順 | 定義・用語の羅列から始める |
| P3 | **Teach-Back が習熟の定義** | 「素人に説明できる」が完了条件 | 選択問題の正答だけを完了にする |
| P4 | **同名異義語を最初に区別** | 「ストック」「システム」「ダイナミクス」等の言葉の違いを最初に丁寧に | 混同したまま進める |
| P5 | **具体→抽象** | 具体例で掴んでから、後半（Unit 7–8）で抽象化・メタ化 | 抽象概念から始める |
| P6 | **学ぶ→やってみる→例で定着→確認→教え返し** | 各ユニットを5段で構成 | 確認ゲートだけにする |

## 2. 対象と到達像

- **主:** 中学2年生（理科・社会・数学の既習で到達可能）
- **到達像ルーブリック**（fourier L0–L4 を適用）

| レベル | 名前 | 判定 |
|--------|------|------|
| L0 | 体験 | 身近な例で「何が起きているか」を日常語で言える |
| L1 | 構造 | ストック・フロー・フィードバック・ボトルネックの役割を指差し説明できる |
| L2 | 記号 | 因果ループ図・ストックフロー図の要素を「なぜ」で説明できる |
| L3 | **Teach-Back（目標）** | 素人役に数分で教え、典型誤解を自分で訂正できる |
| L4 | 転移（任意） | 学んだ型を新しい領域（学校行事・スポーツ等）へ応用できる |

**各ユニットの完了条件 = L3。**

---

## 3. ユニットの標準5段（各ユニット共通）

```
[Hook] 身近な例の体験・問いかけ（「これ、どうしてこうなるの？」）
   ↓
[Reveal] 短い説明（Value→Purpose→Meaning の順・120字×3程度）
   ↓
[Interact] やってみる（図を書く・並べる・予測する）
   ↓
[Check] 確認（選択・予測・対応づけ。数式自由入力は使わない）
   ↓
[Teach-Back] 素人に説明する（テンプレ: 何の話→部品→どう繋がる→例→よくある誤解）
```

## 5. Teach-Back 共通テンプレ（各ユニットの Check で使用）

1. **何の話か** — 1文
2. **部品は何か** — 3つまで
3. **どう繋がるか** — 因果を1本
4. **図はどこを見ればいいか** — 指差し
5. **よくある誤解** — 1つ訂正
6. **素人への一言** — 比喩1つ

🧮 2つの解き方の激突

1. ふつうの算数（全ルート書き出し法）

考えられるルートをすべてノートに書いて足し算し、比べます：

ルート①: 東京 ➔ 神田 ➔ 秋葉原 = 2 + 2 = 4分
ルート②: 東京 ➔ 神田 ➔ 御茶ノ水 ➔ 秋葉原 = 2 + 2 + 2 = 6分
➡ 小さい方を選んで「最短 4分」！
⚠️ 組み合わせ爆発メーター
駅数が 4駅 ➔ 10駅 ➔ 30駅 ➔ 87駅 と増えると：
書き出すべきルート数: 2通り ➔ 80通り ➔ 12万通り ➔ 100穣（1029）通り！
人間には絶対に書ききれません！

2. トロピカル代数（あべこべ算数）

「足し算 ＝ 小さい方を選ぶ（min）」「掛け算 ＝ ふつうに足す（+）」と定義！

$a \oplus b := \min(a, b)$ （和は最小値）
$a \otimes b := a + b$      （積は足し算）
東京から秋葉原への最短時間：
$= (\text{東京}\to\text{神田}\to\text{秋葉原}) \oplus (\text{東京}\to\text{神田}\to\text{御茶ノ水}\to\text{秋葉原})$
$= (2 \otimes 2) \oplus (2 \otimes 2 \otimes 2)$
$= (2 + 2) \oplus (2 + 2 + 2)$
$= 4 \oplus 6 = \min(4, 6) = \mathbf{4}$
🌟 大事な本質：足し算と同じ「3大計算法則」がそのまま使える！
  • 交換法則: $a \oplus b = b \oplus a$ （順序を逆にしても最小値は不変）
  • 結合法則: $(a \oplus b) \oplus c = a \oplus (b \oplus c)$ （どこから比較しても不変）
  • 分配法則: $a \otimes (b \oplus c) = (a \otimes b) \oplus (a \otimes c)$ （$10 + \min(3,8) = \min(13,18) = 13$）
特有の魔法「べき等性」: $a \oplus a = a$ （自分を何度足しても値が増えない！だから重複ルートでも最短が狂わず解ける）

💡 行列積の物理的意味：「1回掛ける ＝ 2区間進む」

数式 $(A_{ik} + A_{kj})$ は、「駅 $i \to k$ の線路1本目」＋「駅 $k \to j$ の線路2本目」の足し算です。
つまり、行列を1回掛け合わせる（$A \otimes A$）代数操作そのものが、「線路を2本連結して2ステップ進む」という物理的意味を表しています！

### 重複ルール（運用）

| 種別 | 正 | 従 |

### 王道 × 直感（validate 必須スロット）

各 `scripts[P-*]`（例外: 看板なし HOOK は script 無しで可）:

| スロット | フィールド | 最低条件 |
|----------|------------|----------|
| intuition | `intuition_1line` | 非空文字 |
| canon story | `story_steps` | 3〜6 件、各 title+body |
| canon morph | `morph_steps` | 2〜8 件 |
| bridge | `why_needed` | 非空 |
| check | `puzzle_cards` + `puzzle_order` | order の id が cards に存在 |

## 4. P1 仕様（実装契約）

### CLI

```text
python tools/expl_pipeline.py validate
python tools/expl_pipeline.py sync
python tools/expl_pipeline.py doctor
python tools/expl_pipeline.py all    # validate → sync → doctor
```

- cwd 想定: 教材ルート `fourier-transform/`
- `sync`: `data/*.json` → `js/data_bundle.js` を **決定的**に再生成
- `doctor`: 各 `FT.DATA_*` が対応 JSON と意味的一致（parse 比較）。不一致で fail
- `validate`: proof 必須スロット + node_index 双方向 + geometry.demo 文字列非空（demo 実装有無は警告可）

### bundle マッピング（固定）

| JSON | グローバル |
|------|------------|
| skill_graph.json | FT.DATA_GRAPH |
| checks.json | FT.DATA_CHECKS |
| copy_ja.json | FT.DATA_COPY |
| math_cards.json | FT.DATA_MATH |
| hotspots.json | FT.DATA_HOTSPOTS |
| proof_scripts.json | FT.DATA_PROOF |
| symbol_readings.json | FT.DATA_READINGS |

出力先頭コメント: `// GENERATED by tools/expl_pipeline.py — do not edit`

### Out of scope（P1）

- proof_ui / app / demos のロジック変更
- 説明文言の改稿
- MD コンパイル（P3）
- nodes/*.md の自動取込

## 5. 日常ループ（P3 以降）

```
1. data/explanations/P-XXXX.json だけ編集（1 proof = 1 ファイル）
2. 必要なら data/explanations/_meta.json（node_index / note）
3. python tools/expl_pipeline.py all
   → merge → data/proof_scripts.json（生成）→ js/data_bundle.js（生成）
4. index.html で該当ノード確認
```

**手編集禁止（生成物）:** `data/proof_scripts.json` / `js/data_bundle.js`

### P2 書き分け（重複禁止）

| 書く内容 | 正本 | 書かない場所 |
|----------|------|----------------|
| 式の直感・王道ストーリー・morph・puzzle | `explanations/P-*.json` | copy_ja の lesson に同じ導出を増やさない |
| ノード導入・なぜ来たか（式の前） | `copy_ja.json` | proof に長文 lesson を増やさない |
| 理論カード要約 | `math_cards.json` | proof と二重に長い本文を持たない |
| 下書き | `nodes/*.md` | 実行系は読まない。採用時は P-* へ転記 |

# 現代暗号の基礎

中学2年生が、通信の問題から出発して、有限体・RSA・楕円曲線・ECDLP・実際の通信・PQCまで段階的に学ぶ教材です。

## 開発方針

- 正本は `chapters/*.md`
- 統合HTMLは `index.html`
- ビルダーは `tools/build_html.py`
- 数式はMarkdown内にLaTeXで記述
- 2D図・3D教材は、概念ごとの個別モデルへリンクする。カタログへの一括リンクは補助案内に限定する
- 本編は中学2年生向け、群・有限体・ECDLPの形式的説明は「挑戦コース」として段階表示する

## 生成

プロジェクトルートで実行します。

```powershell
python tools/build_html.py
```

GitHub Pagesなど、ネットワーク接続がある配布先ではKaTeX CDNを使えます。

```powershell
python tools/build_html.py --katex cdn
```

## 学習ストーリー

0. 暗号を読むための数学の道具箱
1. 秘密の通信には何が必要か
2. 時計の算数（剰余）と有限体
3. 公開鍵暗号とRSA
4. 楕円曲線上の点の足し算
5. 有限体上の点群とECDLP
6. 鍵交換・署名・ハッシュを組み合わせた実際の通信
7. 量子ビット・干渉・グローバー・ショア
8. 量子計算機に対抗するPQC
9. 方式ごとの暗号文を作る実演ラボ

## モデルリンク方針

各章の「モデル」欄に、その概念を直接開く個別URLを置きます。個別モデルがまだ存在しない場合は、未作成として記録し、仮のカタログリンクで代用しません。

- リンク正本: `assets/MODEL_LINKS.md`
- 3D Commonsカタログ: 個別モデルを探すための補助リンク

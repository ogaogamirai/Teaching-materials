## 🎯 なぜ「フーリエ変換」なのか？

私たちが日常で使っている **MP3（音楽）**、**JPEG（画像）**、**ノイズキャンセリングイヤホン**、**医療のMRI**——これらはすべて、たった一つの数学的アイデアによって支えられています。

それは、**「どんなに複雑な波や信号も、綺麗な円運動（サイン・コサイン）の足し算に分解できる」** という発見です。

## 🚀 動かし方（MVP 本編）

**`index.html` をダブルクリックでOK**（`file://` 対応。ES modules / fetch 不使用）。

- 緑の「準備完了」が出れば起動成功 → **はじめる**  
- 黄色いエラーが出る場合は、同フォルダの `js/` が欠けていないか確認  
- 進捗は `localStorage`（`ft_mastery_v1`）。ヘッダの「履歴リセット」で消去  
- **旧単体デモ:** `legacy-demo.html`

## 📝 説明データの更新

各证明・解説は `data/explanations/P-*.json`（1 证明 = 1 ファイル）で編集します。
全体の順序やノード対応は `data/explanations/_meta.json` を変更します。

編集後、プロジェクトルートで以下を実行してください。

```
python tools/expl_pipeline.py all
```

`validate` -> `sync` -> `doctor` が順に走り、
`data/proof_scripts.json` と `js/data_bundle.js` が再生成されます。

**手編集禁止（生成物）:** `data/proof_scripts.json` / `js/data_bundle.js`

| # | 名前 | 学習者体験 | 狙い |
|---|------|------------|------|

### 1.2 目標 #29 の読み（重要）

```
第1優先: 理解に足りる説明量・導出の完全性（薄くしない）

```

**矛盾に見えて両立:** 「最初から短い」のではなく、**十分に書いてから研ぐ**。

### 3.1 新しい正本データ：`proof_scripts`

各 **看板式** に1本（全式カバーの単位）:

```yaml
id: PROOF-CIRCLE-YSIN
node: FT-CIRCLE-1
formula_html: "y = R sin(ωt + φ)"
intuition_1line: "回る点の高さを時間で並べると、きれいな波になる。"
why_needed: "フーリエの原子。複雑な波はこれの足し算。"
geometry:           # I2
  demo: "circle_height_trace"
  beats: ["点を回す", "高さだけ残す", "波が現れる"]
morph_steps:        # I3  2〜6 画面状態
  - html: "点 (R cos θ, R sin θ)"
  - html: "高さ = R sin θ"
  - html: "θ = ωt + φ"
  - html: "y(t) = R sin(ωt + φ)"
puzzle_cards:       # I4  ちょうど3〜5枚
  - "円上の点の高さを取る"
  - "角度を時間で進める"
  - "半径が振れ幅になる"
  - "式にまとめる"
puzzle_order: [0,1,2,3]
bridge_from: ["FT-RAD-1", "FT-RATIO-1"]  # I5
depth_layers:
  short: 3 steps
  full: 本文+図+変形  # 説明量は full に置く
```

**完了条件（式ごと）:** パズル正解 または 変形を最後まで再生＋自己説明1行。  
**モジュール完了:** 従来どおり Teach-Back L3。

## 4. 全式インベントリ（カバー対象）

実数主経路で「出てくる式」を列挙し、**漏れなく** proof_scripts を持つ。

| proof_id | 式（看板） | ノード | 優先 |
|----------|------------|--------|------|
| P-PYTH | a²+b²=c² → cos²+sin²=1 | RATIO/章 | P1 |
| P-TRIG-DEF | sin=対/斜, cos=隣/斜 | RATIO | P1 |
| P-RAD | π rad=180°, ω=2π/T | RAD | P0 |
| P-WAVE | y=A sin(ωt+φ) | WAVE | P0 |
| P-CIRCLE | y=R sin(ωt+φ) | CIRCLE | **P0 参照実装** |
| P-SUPER | (f+g)(t)=f(t)+g(t) | SUPER | P1 |
| P-SUM | Σ の読み | SERIES 章 | P1 |
| P-SERIES | f≈Σ(an cos+bn sin) | SERIES | **P0** |
| P-ORTHO | ⟨f,g⟩〜∫fg （意味） | ORTHO | **P0 参照実装** |
| P-COEFF | an〜⟨f,cos⟩ 等 | COEFF | **P0** |
| P-APP | 係数0→再合成 | APP | P1 |
| P-CAP | 4点物語の式一覧 | CAP | P1 |
| P-EULER | e^{iθ}=cos+i sin | EULER | P2（CAP後）**実装済** |
| P-MAP | 級数/離散の位置 | TRANSFORM | P2（CAP後）**実装済** |

**「全数式」の運用定義:** 上表の看板＋学習者画面に出す変形の各行。裏の実装用数値式は対象外。

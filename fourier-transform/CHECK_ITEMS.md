# Check Items — 仕様とアイテムバンク v1

> **原則 P5:** 数式の自由キーボード入力はゲートにしない。  
> **形式:** タップ / ドラッグ / 予測選択 / 並べ替え / チップ穴埋め / テキストTB。

---

## 1. モダリティ（M1–M10）再掲

| ID | 名前 | 学習者操作 | 自動判定 |
|----|------|------------|----------|

## 2. JSON スキーマ（実装契約）

```json
{
  "$schema": "check_item_v1",
  "id": "C-WAVE-01",
  "node_id": "FT-WAVE-1",
  "modality": "M1",
  "prompt": "周期スライダを上げる前に、波はどうなる？",
  "ui": {
    "type": "predict_choice",
    "choices": [
      { "id": "a", "label": "山が低くなる" },
      { "id": "b", "label": "山と山の間隔が広がる" },
      { "id": "c", "label": "波が左右にずれるだけ" }
    ],
    "observe_demo": "wave_period_scrub"
  },
  "answer": { "correct": ["b"] },
  "feedback": {
    "correct": "間隔＝周期。高さは振幅の担当です。",
    "wrong": { "a": "高さは振幅。", "c": "ずれるのは位相。" }
  },
  "misconception_tags": ["MC01"],
  "no_formula_keyboard": true,
  "time_estimate_sec": 40
}
```

### フィールド規則

| フィールド | 必須 | 注 |
|------------|------|-----|
| id | ✅ | `C-` / `D-` / `TB-` 接頭辞 |
| modality | ✅ | M1–M10 |
| no_formula_keyboard | ✅ | 常に true（Challengeモード以外） |
| answer.correct | ✅ | 単一 or 複数ID |
| answer.tolerance | 任意 | M9 用（px または 正規化座標） |
| rubric | M7のみ | 観点IDとキーワード目安 |

**禁止:** `answer.latex`, `input: free_math` を required にすること。

## 5. Teach-Back ルーブリック（M7）

観点（各 0–2点、合計12点、**合格 ≥ 8** かつ観点1と3が ≥1）:

| 観点 | 見るもの | キーワード目安（自動下書き用） |
|------|----------|--------------------------------|
| R1 ゴール | 何のための話か | 画像, 圧縮, 波, 分解 |
| R2 部品 | 3つまで | 振幅, 周波数, 係数, 円, sin |
| R3 因果 | どう繋がるか | 重ねる, 取り出す, 捨てる |
| R4 式の指差し | 記号を部品に対応（カード選択可） | 係数, 和, 周波数 |
| R5 誤解訂正 | 典型誤を1つ | 間引き, 振幅≠周波数 |
| R6 比喩 | 素人向け一言 | レシピ, 音の成分, 絵の具 |

初期実装: 学習者自己評価チェックリスト + 模範例の並列表示。  
LLM採点は後段オプション（オフラインでも完結すること）。

## 6. チップ語彙（Faded / Mapping 共用）

MVPで使う選択チップ例（自由入力の代替）:

```
振幅 / 周期 / 位相 / 周波数 / 半径 / 角速度
足す / 重ねる / 打ち消し / 取り出す / 似ている度
低周波 / 高周波 / 係数を残す / 係数を捨てる
sin / cos / 和 / 大きな係数 / 小さな係数
```

数式記号（∫, Σ, e^{iθ}）は **画面表示とホットスポット** に限り、入力させない。

# 第2章：なぜ数が爆発するのか〜全部回って戻るルートを数える〜

## 0. なぜこの章を学ぶのか（価値・目的・意味）

### 価値（何を目指すか）
第1章は、「**A から D へいちばん早い一本**」 を探す話だった。  
でも現実には、もっと欲張りな注文がある。

> 修学旅行でいくつかの観光地を全部見て宿に戻る。  
> 配送トラックが得意先を全部回って営業所に戻る。

「全部回って戻る」ルートは、街が少し増えただけで候補がとんでもない数になる——とよく言われる。  
**その数字が、カンではなく計算で出てくる** と分かると、「なぜ全部試し尽くせないのか」「次の章の工夫がなぜ必要か」が腹に落ちる。それがこの章の価値です。

### 目的（何を成すか）
1. 4つの街の巡回を、**樹形図で1本ずつ数える**  
2. 「右回りと左回りは同じ」と気づいて、**2で割る理由**を納得する  
3. 街の数を増やしたとき、候補がどう跳ね上がるかを表で見る  

この「全部回って戻る最短（や候補の多さ）を扱う問題」を、正式名称 **巡回セールスマン問題（Traveling Salesman Problem / TSP）** と呼びます。名前は覚えなくてもよい。中身——全部回って戻る——が大事。

### 意味（各手段の役割）と必然性
| 登場するもの | 役割（この章での意味） |
|---|---|
| 樹形図 | 「次にどの街へ行くか」の枝分かれを目に見える形にする |
| 階乗 $n!$ | 枝の本数をかけ算で一気に数える記号 |
| $\div 2$ | 向きが逆なだけの双子ルートを、二重カウントしないため |
| 街の数を増やす表 | 「少し増えただけなのに手に負えない」差を実証する |

**なぜこの章が第1章の直後に必要か:**  
「一本の最短」の感覚のまま全部回る問題に入ると、「ちょっと街が増えただけ」に見える。  
数え方を手で一度やらないと、第3章の近似も、後のZDDも、**大げさな工夫**に見えてしまう。  
爆発を自分で数えて初めて、次の工夫が必然になることがわかるでしょう。

> 第1章との言葉のちがい: 第1章の「ルート」は **始点→終点の一本**。この章の「ルート」は **全部の街を巡る輪（巡回）**。同じ「ルート」でも中身が違うので、混同しないようにする。

## 1. 物語①：4つの街を、樹形図で数え切る

街は **A, B, C, D** の4つ。やることば「全部を一度ずつ訪れて、出発した A に戻る」。

出発は A に固定する（輪をどこで切って話し始めても同じ輪、なので、スタートを決めて数えやすくする）。

### まず一本だけ、スタートからゴール（帰還）まで完走する

樹形図のいちばん左の枝を、コマ送りで追う。

次は B / C / D のどれか。

#### コマ2：B を選ぶ

#### コマ3：C を選ぶ

<!-- map: route=tour | step=3 | edge=bc | branch=1 | taken=ab | at=C -->

#### コマ4：D へ

<!-- map: route=tour | step=4 | edge=cd | branch=1 | taken=ab,bc | at=D -->

#### コマ5：A へ帰還

<!-- map: route=tour | step=5 | edge=ad | branch=1 | taken=ab,bc,cd | at=A -->

**完成した一本**: A → B → C → D → A …… これを ① と呼ぶ

これが「世界線を1本完走する」感覚。  
まだ他の枝は見ない。① が最後までつながってから、全体の木を見る。

### 樹形図の全体（枝が何本あるか）

6本の枝が **重ならず** 下へ伸びるのが樹形図です。  
いちばん左の枝を、上のコマ送り（① = A→B→C→D→A）と重ねて読んでください。

![樹形図 — 6通り（出発 A 固定）](figures/ch02_tsp_tree.svg)

#### ミニマップ（選択グラフ）

樹形図は段ごとに **別ノード** として6枝を並べます。  
ミニマップは B・C・D を **1つずつ** にまとめ、「2→3→4番目の選択」だけを横方向に追う見方です（6通りの一覧には向きません）。

![ミニマップ — 選択グラフ](figures/ch02_tsp_graph.svg)

人間の言葉だと:

1. 2番目の街は、残り3つから選ぶ → **3通り**  
2. 3番目は、残り2つから選ぶ → **2通り**  
3. 最後の街は、残り1つ → **1通り**  

かけ算すると:

$$
3 \times 2 \times 1 = 6
$$

**よみ**: 「さんかけるにかけるいちは、ろく通り」

この「ある数から1まで順にかける」計算を **階乗** と呼び、$3! = 6$ と書く。

**よみ**: 「3の階乗は6」

街が $N$ 個で出発を1つ固定するなら、残りの並べ方は $(N-1)!$ 通り。  
4つの街なら $(4-1)! = 3! = 6$ で、上の樹形図と一致する。

### 6本すべて（一覧）

| # | 巡回の順番 |
|---|---|
| ① | A → B → C → D → A |
| ② | A → B → D → C → A |
| ③ | A → C → B → D → A |
| ④ | A → C → D → B → A |
| ⑤ | A → D → B → C → A |
| ⑥ | A → D → C → B → A |

<details>
<summary>思考実験: 樹形図を「全部同時に」見ると疲れる理由</summary>

6本を一度に眺めようとすると、頭の中で枝が交差して混乱しやすい。  
だからこの章では、①を完走してから全体を見、次の節でまた①と⑥だけを取り出す。  
**一本ずつ完走 → それから並べる** が、数え上げの基本姿勢。
</details>

## 2. 物語②：①と⑥は「双子」——だから2で割る

6通りと数え終わったあとに、もう一段ある。

### ①を完走したあと、⑥だけを取り出す

- **①（右回り）**: A → B → C → D → A  
- **⑥（左回り）**: A → D → C → B → A  

![① 右回り と ⑥ 左回り（双子）](figures/ch02_tsp_mirror.svg)

道がどちら向きにも同じ長さで通れるなら、①と⑥は **通る道のセットも合計距離も同じ** で、進む向きだけが逆の双子である。

ここで比較の3要素を揃える。

| 項目 | 内容 |
|---|---|
| **比較対象** | 完成した巡回①と⑥（どちらも「全都市を回って戻る輪」） |
| **比較方法** | 通る辺の集合と、合計距離（向きは無視してよいか） |
| **選択の根拠** | 同じ辺・同じ距離なら「別ルート」として二重に数えない |

だから対称な（往復で距離が同じ）問題では、最後に 2 で割る。

$$
6 \div 2 = 3
$$

**よみ**: 「6通りを2で割ると、区別したい巡回は3通り」

4つの街なら、実質的に違う輪は **3通り** だけ、と覚える。

## 3. 公式と、街を増やしたときのコントラスト

まとめると、よく使う式は次のとおり。

$$
\text{区別したい巡回の数} \;=\; \frac{(N-1)!}{2}
$$

**よみ**: 「エヌ個の街なら、出発を固定した並べ方 $(N-1)!$ を、向きの双子の分だけ2で割る」

| 部品 | 意味 |
|---|---|
| $(N-1)!$ | 樹形図の枝——「次はどれ？」のかけ算 |
| $\div 2$ | 右回り／左回りの同一視 |

### コントラスト実験：街が少し増えるとどうなるか

「街がだいたい同じくらい」だと差が見えない。だから **5・10・20** と飛ばして比べる。

| 街の数 $N$ | 計算 | おおよその数 | しらみつぶしの感触 |
|---|---|---|---|
| 5 | $4!/2 = 12$ | 12通り | ノートでも数え切れる |
| 10 | $9!/2$ | 約18万通り | コンピュータならまだ届く規模 |
| 20 | $19!/2$ | 約 $6\times10^{16}$（約6京）通り | 全部試すのは現実的でない |

膝打ちポイント:

> 街が「5 → 20」は、個数としては4倍程度の話に聞こえる。  
> なのに候補の数は、手計算の世界から、宇宙の年齢を持ち出すくらいの世界へ跳ねる。  
> これが **組合せ爆発**——かけ算（階乗）が積み重なると、感覚よりずっと速く大きくなる、ということ。

「何億年かかる」といった具体的な年数は、コンピュータの速さの仮定で変わる。  
この章で握るべきなのは年数そのものではなく、**全部試し尽くせない規模にすぐ達する** という事実である。

## 4. 理解チェック

**問題**  
「東京・大阪・京都」の3都市だけを全部回って戻るとき、公式 $\dfrac{(N-1)!}{2}$ は何通りか。

<details>
<summary>答えと解説（クリックして開く）</summary>

$N=3$ なので $\dfrac{2!}{2} = \dfrac{2}{2} = 1$ 通り。  
3点の輪は、右回りと左回りを同じと見ると、実質1パターンしかない。
</details>

## 5. 手を動かす課題

**[基礎]**  
$N=6$ のとき $\dfrac{(N-1)!}{2}$ を計算せよ。

<details>
<summary>答え</summary>

$\dfrac{5!}{2} = \dfrac{120}{2} = 60$ 通り。
</details>

**[基礎]**  
樹形図の左端だけを使い、A から始めて「自分だけの一本」を文章で完走せよ（例: 次にCを選ぶ、次に…）。

**[発展]**  
一方通行が多く、「行き」と「帰り」でかかる時間が違う町では、なぜ最後に 2 で割ってはいけないか。

<details>
<summary>発展の答え例</summary>

右回りと左回りで通る向きが変わり、合計時間が同じとは限らない。双子ではなく別物なので、$\div 2$ すると数え落とす。
</details>

## 6. もう一歩深く（任意）

この章の本筋は「樹形図 → 階乗 → ÷2 → 爆発の感触」まで。以下は余力用。

<details>
<summary>対称TSPと非対称TSP</summary>

往復で距離が同じ想定が **対称TSP**（この章の $\div 2$ あり）。  
一方通行などで向きでコストが違うのが **非対称TSP**（$\div 2$ しない。目安は $(N-1)!$）。
</details>

<details>
<summary>出発地を固定する理由</summary>

同じ輪を「どこをスタートと呼ぶか」で何通りにも数えないため。  
$\div 2$ は「向き」の同一視で、スタート固定とは別の調整。
</details>

<details>
<summary>第1章の最短路とのちがい</summary>

| | 第1章 | 第2章 |
|---|---|---|
| 欲しいもの | 始点→終点の一本 | 全点を巡る輪 |
| 候補の増え方 | 道順はあるが「全巡回」ほどではない | 階乗で爆発しやすい |
| 次に必要な工夫 | A\* などで無駄を減らす | 近似（第3章）や、後の圧縮（ZDD） |
</details>

<details>
<summary>「難しい問題」ということ（名だけ）</summary>

TSP の最適解を一般に求める問題は、計算の世界ではとても手強い部類（NP困難と呼ばれる）に入る。  
名前より先に実感してほしいのは、上の表の爆発である。厳密な定義は今は不要。
</details>

## 7. 次章への橋

全部試し尽くせないなら、配送も旅行も諦めないといけないのか。  
いいえ。次の第3章では、**100点満点を常に保証しなくても、短い時間で十分良い巡回を出す** 工夫——ヒューリスティック——を見る。

そのさらに先には、「一本の良い解」だけでなく **解の集まりを圧縮して扱う** 道（第4章以降の ZDD）もある。  
どちらも、この章で感じた「爆発」が動機になる。

# EX4 — 解答・解説（会議が多すぎて仕事が進まない）

> **前提:** この演習の狙いは「会議の増加と成果物の遅れ」を、ストック（仕事の山）と遅れで見る SD と、ボトルネックで見る TOC の両方を使うこと。

---

## 1. 問題（UDE）の整理

- UDE1: 1日の会議が5〜6件
- UDE2: まとまった仕事の時間がない
- UDE3: 会議で決まらない→さらに会議
- UDE4: 成果物が遅れる

## 2. SD の切り口（ストックと悪循環）

**ストックとフロー（Unit 2）:**

```
仕事の処理（フローOUT）◀── [仕事の山（ストック）] ──▶ 新しい仕事（フローIN）
                              ↑ ここがたまっている
```

**悪循環のループ:**

```
会議が多い
   ▼
まとまった仕事の時間がない
   ▼
成果物が遅れる
   ▼
進捗確認・調整の会議が増える
   ▼
（最初に戻る＝悪循環）
```

これは**負のループ（悪循環）**。会議を増やせば増やすほど、仕事が進まず、さらに会議が増える。

**参照モード（Unit 9）:** 放置すると、仕事の山（ストック）がどんどん増え、成果物の遅れが拡大する。

**介入点（SD）:**
- 悪循環を**切る**: 会議の数を減らす（会議を開く判断基準を設ける）
- ストックの**出フローを増やす**: まとまった時間を確保する（会議をまとめて1日にする等）
- 遅れ（Unit 4）: 会議を減らしても、成果物の遅れが回復するまで時間がかかる。**待つ設計**

## 3. TOC の切り口（ボトルネック）

**ボトルネック（Unit 5）:** 仕事が「たまっている」場所はどこか → **会議（あるいは会議の準備）**。

時間という資源のうち、会議に取られる時間が制約になっている。

**5つの集中ステップ（Unit 6）:**
1. 見つける: 制約は「まとまった仕事の時間」
2. 活用する: 会議を短縮・整理する（アジェンダを事前共有、決定事項だけ話す）
3. 従属させる: 会議の頻度を、進捗に合わせて調整する（「月1回の全体会議」に固定しない）
4. 強化する: まとまった時間を守る（会議禁止の時間帯を作る）
5. 繰り返す: 次のボトルネック（会議の準備・調整）を探す

**根本原因（CRT・Unit 7）:** 「会議が目的化している」＝会議を開くこと自体が仕事になっている。

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 仕事の山（ストック）が増える悪循環と、回復の遅れ | なぜ会議が増え続けるか。悪循環を切る |
| TOC | 制約（まとまった時間）と根本原因（会議の目的化） | どこが滞っているか。会議を減らす仕組み |

- SD: 「会議→遅れ→さらに会議、という悪循環。会議の入り口を切る＋回復まで待つ」
- TOC: 「制約は『まとまった時間』。会議を減らして時間を確保する」

## 5. Teach-Back 用の要点

- 「会議が多すぎて仕事が進まない」は、**会議を増やすほど遅れる悪循環**
- 仕事の山（ストック）がたまっている場所＝会議が制約
- 解決は「会議を減らす」＋「効果が遅れることを織り込んで待つ」

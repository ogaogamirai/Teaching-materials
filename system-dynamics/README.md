# system-dynamics — システムダイナミクス×TOC 学習教材

> 中学2年生から一般社会人が、順を追って学べる、分かりやすく・効率的・短期間で学べる教材。
> 中学2年生でも、読み進めることで**大学学部生レベルの理解**まで到達できることを目指す（各ユニットは「基本編→発展編」の2層構造）。
> キャプテンと対話しながら1ユニットずつ作る。**学びながら作る教材。**

---

## 教材のねらい

物事の「つながりを丸く捉える」思考（システムダイナミクス）と「どこを直すか絞る」思考（TOC）を、
1つの「システム思考」として身につける。

```
見る（SD: 構造の全体像） → 直す（TOC: 制約への集中） → 抽象化（自分たちの言葉で）
```

## 対象と到達像

- **対象:** 中学2年生〜一般社会人
- **到達像:** 中学2年生でも順に読み進めることで**大学学部生レベルの理解**（数理的表現・シミュレーションによる構造分析）まで到達できる
- **ゴール（Teach-Back）:** 素人に「システムダイナミクスで物事をどう見るか」を自分の言葉で説明できる

## レイヤー構造（二段構え）

```
【発展編（大学レベル）】 数理的表現・シミュレーション・厳密な記述
         ▲ 意味を深める（同一テーマのまま、層を上げる）
【基本編（中2〜）】      身近な例・直感・図・言葉での説明
```

## 理論ルート（Math Bridge）— 数理前提の補助Unit

発展編で使う数式の前提は `math-bridge/` の補助Unitで学ぶ。中2は発展編前に挟み、数学が得意な人はスキップ可。**本編に「どこまで必要か」を補記**する。

```
基本編（中2〜） ──→ 発展編（大学レベル）
      │                    ▲
      └──→ 【理論ルート / math-bridge/】 ─┘
```

## 設計方針（既存知見からの引用）

- **Value → Purpose → Meaning**: なぜやるか（価値）を最初に → 具体例 → 意味（キャプテン認知プロファイル）
- **学ぶ → やってみる → 例で定着 → 確認 → 教え返し** の5段（KNOW-UX-LEARN-PROCESS-BEFORE-CHECK）
- **Teach-Back が習熟の定義**: 「解ける」ではなく「人に説明できる」（fourier LEARNING_DESIGN.md P3）
- **動機主導**: 身近な例（貯金・SNS・風邪の流行）から入る
- **同名異義語は最初に区別**: 「ストック」（在庫と株の「ストック」等）
- **数式は表示し説明する**: 使う数式は必ず意味・読み方つきで（P9）
- **数理前提は理論ルートで補う**: 発展編の前提は math-bridge（P10）

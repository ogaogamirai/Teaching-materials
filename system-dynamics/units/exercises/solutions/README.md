## 使い方

1. `exercises/exN_*.md`（問題カード）で問題を解く
2. 解き終わってから、対応する `solutions/exN_*_solution.md` を見る

## 解答の形式

各解答は「SD の切り口」と「TOC の切り口」の2つを基本とし、題材に応じて使い分ける。

```
# EX◯ — 解答・解説

## 前提（この演習の狙い・使う道具）
## SD の切り口（参照モード→構造→介入点→政策抵抗）
## TOC の切り口（制約→CRT→蒸発する雲→Injection）
## 対比（SDとTOCで見え方がどう違うか）
## 解答の要点（Teach-Back用）
```

# EX1 — 解答・解説（朝起きられない悪循環）

> **前提:** Unit 7・8 の例題（解答つき）。ここでは Unit 7（CRT）と Unit 8（蒸発する雲・Injection）の2段階の解答をまとめる。

---

## 1. 問題（UDE）の整理

- UDE1: 朝、起きられない
- UDE2: 朝ごはんを食べない
- UDE3: 授業中に眠くなる
- UDE4: 成績が下がった
- UDE5: イライラして友達と衝突する

## 2. Unit 7: CRT（根本原因の特定）

### 因果ツリー（散らばった5つの症状 → 1つのRoot）

```
[UDE: 朝、起きられない] → [UDE: 朝ごはんを食べない] → [Cause: エネルギー不足] ─┐
                                                                             ├─► [Cause: 睡眠不足] ◀─ [Cause: 夜更かし] ◀─ [Cause: スマホ] ← Root
[UDE: 授業中に眠くなる] → [Cause: 集中力低下] → [UDE: 成績が下がる] ───────────┘
[UDE: イライラする] → [UDE: 友達と衝突する] ────────────────────────────────────┘
```

### 因果の検証（Unit 7 §4.5）
| 矢印 | 検証 | 判定 |
|---|---|---|
| 睡眠不足→朝起きられない | 3・4・7 OK | 合格 |
| 眠くなる→成績が下がる | 中間に「集中力が続かない」を追加（8） | 合格 |
| 朝ごはん→眠くなる | **5番の危険**（実は睡眠不足が原因かも） | 修正 |

### Root（根本原因）
**夜更かし（寝る前にスマホを見てしまう）**

## 3. Unit 8: 蒸発する雲と Injection

### 蒸発する雲
```
[目的C] 健康で元気に毎日を過ごしたい
   ／                          ＼
[要求A] 楽しい時間を持ちたい  [要求B] 十分に眠りたい
   │                              │
[行動A] 夜遅くまでスマホを見る ←→ [行動B] 早く寝る
```

### 対立の前提（思い込み）
- 「楽しい時間は夜しかない」
- 「スマホを見る＝夜遅くまで」
- 「眠る時間が減っても大丈夫」

### Injection（前提を外す）
- 昼間にスマホを見る時間を決める・楽しい活動を別の時間に作る
- スマホの利用時間を制限する（タイマー・自分ルール）
- 睡眠の大切さを知る（遅れの効果: 翌日の集中力）

→ 「楽しさ」と「睡眠」の両方をかなえる仕組み（例: スマホは21時まで、夜は読書に変える）

### FRT
- スマホを制限 → 「連絡を見逃す」？
  → 対策: 朝・昼に確認時間を確保
- 夜が退屈 → ?
  → 対策: 読書など代替の楽しみを用意

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 悪循環のループ、遅れ（寝る時間→朝の起きやすさ） | なぜ1つの対策で止まらないか |
| TOC | 根本原因（夜更かし）、対立（楽しさ vs 睡眠） | どこを直すか。前提を外して両立 |

- SD: 「悪循環の輪。疲れ→夜更かし→起きられない。ループを切る」
- TOC: 「根本は夜更かし。『楽しい＝夜』という前提を外すと両立できる」

## 5. Teach-Back 用の要点

- 5つの症状はバラバラに見えるが、1つのRoot（夜更かし）に収束する
- 解決は「朝の努力」でなく「**夜の仕組みを変える**」こと
- 「我慢」ではなく「前提を外す仕組み」で楽しさと睡眠を両立

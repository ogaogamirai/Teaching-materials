# Unit 8 — 演習B（基本編）: 解消 — 蒸発する雲で対立を解体し、根本原因を直す

> **対象:** 中学2年生〜一般社会人
> **ゴール（L3 Teach-Back）:** 蒸発する雲で対立を解体し、対立の前提を外す解消策（Injection）を設計できる。新たな問題（FRT）も確認できる
> **所要目安:** 20〜30分（Unit 7 の続き）
> **準備:** Unit 7 で作ったCRT・演習カード

---

## 1. Hook — 「どっちを取るか」の対立

「朝起きられない」を直すために、夜更かしをやめたい。でも…

- 「スマホを寝る前に見たい」←→「早く寝なきゃいけない」

この2つは対立していますか？ 実は、**対立しているように見えて、実は対立していない**ことがよくあります。これを解く道具が「蒸発する雲」です。

## 2. 蒸発する雲（Evaporating Cloud）とは

### Value（価値）
対立を「どちらかが折れる（妥協）」で解くと、片方が不満を残します。**蒸発する雲は、対立の前提を外して「両方かなえられる」道を作る**ので、雲（対立）が「蒸発」します。

### Purpose（目的）
対立している2つの行動の、奥にある「共通の目的」を見つける。

### Meaning（意味）

```
        [目的C] 共通の上位目的
        ／            ＼
  [要求A]              [要求B]
     │                   │
  [行動A]  ←→対立←→  [行動B]
```

- **目的C**: 両者が本当に望んでいる共通の上位目的
- **要求A/B**: その目的を達成するための条件
- **行動A/B**: 実際にやっていること（これが対立している）

**ポイント:** 行動AとBが対立していても、**目的Cは共通**であることがほとんど。

## 3. 蒸発する雲の書き方（4ステップ）

```
Step1 対立している2つの行動を書く（A vs B）
Step2 それぞれの行動の「要求」（なぜそれをやるのか）を書く
Step3 その下の「共通の目的」を書く
Step4 対立を「蒸発」させる前提を探す（Injection）
```

## 4. 例題（EX1の続き: 朝起きられない）— 解答つき

### 蒸発する雲を描く

```
        [目的C] 健康で元気に毎日を過ごしたい（学校生活を楽しみたい）
        ／                                  ＼
  [要求A] 楽しい時間を持ちたい             [要求B] 十分に眠りたい
     │                                         │
  [行動A] 夜遅くまでスマホを見る      ←→   [行動B] 早く寝る
```

![fig](figures/unit8_evaporating_cloud.svg)

**対立しているのは「行動A vs 行動B」。でも目的C（元気に過ごしたい）は共通。**

### 対立の「前提」を探す（ここが肝心）

なぜ行動Aと行動Bが対立するのでしょう？ そこには**隠れた前提（思い込み）**があります。

> **前提: 「楽しい時間は夜しかない」「スマホを見る＝夜遅く」**

この前提が実は間違っていたら？

### Injection（解消策）— 前提を外す

| 前提（思い込み） | それを外す Injection |
|---|---|
| 「楽しい時間は夜しかない」 | 昼間にスマホを見る時間を決める・楽しい活動を別の時間に作る |
| 「スマホを見る＝夜遅くまで」 | スマホの利用時間を制限する（タイマー・自分ルール） |
| 「眠る時間が減っても大丈夫」 | 睡眠の大切さを知る（遅れの効果: 翌日の集中力） |

**Injectionは「妥協」ではない。** 「楽しさ」と「睡眠」の両方をかなえる新しい仕組み（例: スマホは21時まで、夜は読書に変える）を作ります。こうすると、**対立（雲）が消えて、根本原因（夜更かし）が直接解消**されます。

## 5. InjectionとFRT（新たな問題の確認）

### Injection（注入・解消策）
根本原因を解消する新しい仕組み・ルール・仕掛け。

- 根本原因を「直す」のではなく「**対立の前提を外す**」形にするのがTOC流
- 例: 「夜はスマホを別の部屋に置く」という仕組み

### FRT（Future Reality Tree / 未来問題ツリー）
Injectionを入れたら、**新たな問題が生まれないか**を確認する。

```
Injection（例: 夜はスマホを別の部屋に置く）
   │
   ▼
良い結果: 夜更かしが減る → 朝起きられる
   │
   ▼
新たな問題?: 「連絡を見逃す」「夜が退屈」
   │
   ▼
対策: 連絡は朝確認する / 退屈な夜の楽しみ（読書など）を用意
```

**完璧な対策はない。** FRTで「新たな問題」を予想し、その対策まで考えるのがTOCの丁寧さです。

## 6. Check — 確かめてみよう

1. 蒸発する雲の「目的C」とは何？
2. Injectionは「妥協」と何が違う？
3. FRTは何を確認する道具？

> **答え（下を見る前に自分で）:**
> 1. 両者が共通に望む上位目的　2. 妥協は片方が諦める。Injectionは対立の前提を外して両方かなえる　3. 解消策が新たな問題を生まないか

## 7. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「対立はどちらかが折れればいい」 | 妥協は不満を残す。前提を外せば両方かなえられる |
| 「Injection = 努力・我慢」 | 努力・我慢ではなく、**仕組み（環境）を変える** |
| 「解決策を思いつけば終わり」 | FRTで新たな問題まで確認するのがTOC流 |

## 8. やってみよう — 選択式演習（Unit 7 の続き）

Unit 7 で選んだ題材の続きで、Step5〜7をやる。

1. **対立の構造**を見つける（何と何が対立している？）
2. **蒸発する雲を描く**（共通の目的Cを見つける）
3. **対立の前提**を探す（なぜ対立しているように見えるのか）
4. **Injection** を設計する（前提を外す仕組み）
5. **FRT** で新たな問題と対策を確認する
6. **Teach-Back**

- ヒントは各演習カードに記載。

## 9. Teach-Back — 素人に説明しよう

1. **何の話か:** 「対立は前提を外せば消える」という話
2. **部品は何か:** 行動A・行動B・共通の目的C・前提・Injection
3. **どう繋がるか:** 対立の下に共通の目的がある。前提を外す仕組み（Injection）で両方かなえる
4. **図はどこを見ればいいか:** 目的C（共通点）と、隠れた前提
5. **よくある誤解:** 妥協ではなく前提を外す
6. **素人への一言:** 「夜スマホを見たい（A）と早く寝たい（B）は、どっちも元気でいたい（C）のためだよ。スマホを21時までにする、がInjection。我慢じゃなく仕組み」

## まとめ（Takeaway）

- **蒸発する雲** = 対立を「共通の目的」から見直す道具
- **対立の前提**を見つけると、対立が「蒸発」する
- **Injection** = 前提を外す仕組み（妥協ではなく環境の変更）
- **FRT** = 解消策が新たな問題を生まないか確認
- 根本原因（Unit 7）を、前提を外して解消（このUnit）すると、システム全体が改善する
- 次回は社会人向けの実務演習（任意）

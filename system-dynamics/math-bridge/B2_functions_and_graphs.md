# B2 — 関数とグラフ：変化の割合を見える化する

> **対象:** 発展編に進む中学2年生〜
> **ゴール:** 関数のグラフを読み、傾き＝変化の割合であることを説明できる
> **所要目安:** 10分
> **前提:** B1（変化率と割合）

---

## 1. なぜこれを学ぶのか

変化の様子は、式より**グラフ**で見ると一目で分かります。「時間の経過とともに、量がどう変わるか」をグラフにすると、システムの動きが直感的に見えます。

## 2. 関数とは

一方（時間など）を決めると、もう一方（量）が1つに決まる関係。

$$ y = 変化の割合 \times t $$

- $t$ … 時間（横軸）
- $y$ … 量（縦軸）
- 変化の割合が大きいほど、グラフの傾きが急

## 3. グラフで見る「変化の割合」

```
y（量）
│            ／ 変化の割合 大（傾き急）
│         ／
│      ／
│   ／  ／ 変化の割合 小（傾きゆるい）
│／
└──────────── t（時間）
```

**傾き＝変化の割合。** グラフが急なほど、速く変わっている。

- 右上がり（傾き 正）→ 増えている
- 右下がり（傾き 負）→ 減っている
- 水平（傾き 0）→ 変わっていない

## 4. お風呂の水位をグラフで見る

Unit 2 の発展編では、水位が「入り − 出」で決まると学びます。グラフで言うと：

| 入りと出の関係 | 傾き | グラフ |
|---|---|---|
| 入り > 出 | 正 | 右上がり |
| 入り < 出 | 負 | 右下がり |
| 入り = 出 | 0 | 水平 |

グラフの「傾き」が、そのまま変化の割合なのです。

## 5. Check — 確かめてみよう

1. グラフが右上がりのとき、量は増えている？ 減っている？
2. 傾きが急＝変化の割合は大きい？ 小さい？
3. 水平なグラフの傾きは？

> **答え:** 1. 増えている　2. 大きい　3. 0（変化なし）

## 6. まとめ

- 関数 = 時間と量の対応関係
- グラフの**傾き = 変化の割合**
- 傾きの正・負・0 = 増加・減少・横ばい
- 次は「傾き」を瞬間ごとに測ることを考える

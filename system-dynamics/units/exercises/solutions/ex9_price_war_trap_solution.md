# EX9 — 解答・解説（値下げの罠：売上は伸びたのに利益が減った）

> **前提:** この演習は Unit 9（SD）と Unit 10（TOC）で**同じ問題**を両方の切り口から解く、対比演習の代表例。解答も SD・TOC の2つを用意する。

---

## 1. 問題（UDE）の整理

- UDE1: 利益が減った
- UDE2: 1個あたりの利益率が下がった
- UDE3: 販売数は増えたのに儲かっていない
- UDE4: コスト（発送・返品）が増えた

## 2. SD の切り口（Unit 9）

### 参照モード
```
利益
  │         ／（売上は伸びている）
  │      ／
  │   ／   ／（でも利益は…）
  │ ／  ／
  │／／
  │      ＼
  │       ＼  ← 放置すると利益がさらに落ちる
  └────────────→ 時間
```

### 構造（2つのループ）
```
【正のループ】 値下げ → 販売数増 → 売上増 → さらに値下げ
【負のループ】 値下げ → 利益率減 → 利益減 → 投資できない → 品質低下 → 販売減
```

**時間の遅れ（Unit 4）:** 正のループ（売上増）はすぐ見える。負のループ（利益率減）は後から効く。だから「売れてるから大丈夫」と錯覚する。

### 介入点
- 正のループを切る（値下げ競争から降りる）
- 負のループを強める（利益率を守る仕組みを作る）
- フローを変える（費用フローOUTを減らす）

### 政策抵抗
「値上げすればいい」→ 販売数が減る（正のループの反動）→ 焦って再び値下げ、に打ち消される。**価格に見合う価値（品質・サービス）を同時に上げる**必要がある。

## 3. TOC の切り口（Unit 10）

### 制約（ボトルネック）の特定
利益（ストック）を増やすのに、制約は「販売数」か？ それとも「利益率」か？
→ **利益率（1個あたりの儲け）** が制約。販売数は増えているのに利益が増えないのだから。

### CRT（根本原因）
```
[利益が減った]
   ▼
[売上（フロー）は増えたが、費用（フローOUT）も増えた]
   ▼
[1個あたりの利益率が下がった]
   ▼
[値下げした]
   ▼
[「売上を増やす＝値下げ」という思い込み] ← 根本原因
```

**根本原因:** 「売上（フローIN）＝良し」という見方。利益（ストック）ではなく売上で判断している。

### 蒸発する雲
```
[目的C] 長期的に儲け続ける（事業を続ける）
   ／                              ＼
[要求A] 売上を増やしたい          [要求B] 利益率を守りたい
   │                                  │
[行動A] 値下げする            ←→  [行動B] 値段を維持する
```

**前提（思い込み）:** 「売上を増やす＝値下げしかない」

**Injection（前提を外す）:** 値下げ以外で売上を増やす方法
- 付加価値を上げる（品質・サービス・デザインで差別化）
- セット販売・定期購入で客単価を上げる
- ボトルネック（EX10）の視点で、儲かる商品に集中する

### FRT
- 付加価値アップ → 価格に見合わない？
  → 対策: 実績・レビューを可視化
- セット販売 → 在庫が増える？
  → 対策: 需要予測・限定数でリスク抑制

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 正のループと負のループの綱引き、売上と利益の時間差、政策抵抗 | なぜ「大丈夫」と錯覚するか。遅れて効く負のループを見る |
| TOC | 制約（利益率）、根本原因（売上で判断）、対立（売上 vs 利益率） | どこを直すか。前提（値下げしかない）を外す |

- SD の答え: 「利益率の負のループが遅れて効く。利益（ストック）を見て、利益率のループを強め、効果を待つ」
- TOC の答え: 「制約は利益率。根本は『売上＝良し』の思い込み。値下げ以外で売上を増やす仕組みを作る」

**両方使うと最強:** SD が「なぜ・いつ」を、TOC が「どこを・どう」を答える。

## 5. Teach-Back 用の要点

- 値下げの罠は「売上（フロー）を見て利益（ストック）を見ていない」こと
- SD: 正のループはすぐ見え、負のループは遅れて効く。利益率のループを強める
- TOC: 制約は利益率。根本は「売上＝良し」の思い込み。値下げ以外で売上を増やす
- 単純な「値上げ」は政策抵抗に遭う。価値とセットで価格を上げる

# EX3 — 解答・解説（クラスの係活動が回らない）

> **前提:** この演習の狙いは「仕事が特定の人に集中する」問題を、ボトルネックと悪循環で見ること。SD のループと TOC のボトルネックの両方を使う。

---

## 1. 問題（UDE）の整理

- UDE1: 仕事がDさんに集中する
- UDE2: 連絡が遅れる
- UDE3: みんなが協力しない
- UDE4: 準備が間に合わない

## 2. SD の切り口（悪循環のループ）

```
Dさんに仕事が集中する
   ▼
Dさんは忙しくて、他の係と連絡できない
   ▼
連絡が遅れる → みんなが「知らなかった」と協力しない
   ▼
Dさんがさらに一人で仕事を抱える
   ▼
（最初に戻る＝悪循環）
```

これは**負のループ（悪循環）**。Dさんが「頑張って全部やる」ほど、みんなの協力が減り、さらにDさんに集中する。

**介入点（SD）:**
- 悪循環を**切る**: 「Dさんが全部やる」をやめ、**連絡を先に回す**仕組みを作る（連絡を待たず、先に知らせる）
- 遅れ（Unit 4）: 連絡の効果がすぐ出るとは限らない。定期的な確認が必要

## 3. TOC の切り口（ボトルネック）

**ボトルネック（Unit 5）:** 仕事が「たまっている」場所はどこか → **Dさん**（一人に集中）。

Dさんが「1人でできる量」が制約（ボトルネック）になっている。

**5つの集中ステップ（Unit 6）:**
1. 見つける: ボトルネックは Dさん（一人への集中）
2. 活用する: Dさんが無駄に抱えている仕事を洗い出す（本当にDさんしかできない？）
3. 従属させる: 他の係は、Dさんの進み具合に合わせて仕事を分担する（Dさん任せにしない）
4. 強化する: 仕事の割り振りを明確にする（担当表を作る）
5. 繰り返す: 次に滞る場所（ボトルネック）を探す

**根本原因（CRT・Unit 7）:** 「仕事の割り振り・担当が不明確」＝誰が何をやるかが決まっていない。

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 悪循環のループ（Dさんに集中→協力が減る） | なぜDさん任せが続くか。ループを切る |
| TOC | ボトルネック（Dさん）と根本原因（担当不明確） | どこが滞っているか。担当表で直す |

- SD: 「Dさんが頑張るほど悪循環する。連絡を先回しにしてループを切る」
- TOC: 「ボトルネックはDさん。根本は担当が不明確。割り振りを明確にする」

## 5. Teach-Back 用の要点

- 「一人に仕事が集中する」は、**その人が頑張りすぎるほど悪化するループ**
- ボトルネックの視点: 仕事がたまっている場所（Dさん）が制約
- 解決は「Dさんが頑張る」ではなく「**分担・担当を明確にする仕組み**」でループを切る

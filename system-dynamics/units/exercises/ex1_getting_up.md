# EX1 — 朝起きられない悪循環（例題・解答つき）

> 対象: 中2　使う要素: 負のループ・時間の遅れ
> 配置: Unit 7 の例題（解答つき）。Unit 8 で続き（対立の解体）を行う

---

## シチュエーション

Aさんは「朝起きられない」ことに悩んでいます。次のような状態が続いています。

- 夜更かししてしまう（スマホを触ってしまう）
- 朝、起きられず、遅刻しそうになる
- 慌てて学校に行くので、朝ごはんを食べられない
- 授業中、眠くなってしまう
- 家に帰ると疲れて、また夜更かししてしまう

## 問題（UDE）の列挙

まず、観測できる「不都合な事象」を1項目1文で書き出す。原因や解決策は混ぜない。

- UDE1: 朝、起きられない
- UDE2: 夜更かししてしまう
- UDE3: 朝ごはんを食べられない
- UDE4: 授業中に眠くなる
- UDE5: 家に帰ると疲れている

## 演習ステップ

1. **UDEを列挙する**（上記）
2. **因果でつなぐ** —「Aが起きる、なぜならBだから」の矢印でつなぐ
3. **根本原因を探す** — 矢印が一番多く出ている（= すべてを説明できる）のはどこか
4. **輪を確認する** — 悪循環（負のループ）になっていないか
5. **根本原因を特定する**

## 解答例

### 因果でつなぐ（CRT）

```
[夜更かししてしまう] ←── [スマホを触る]
       │
       ▼
[朝、起きられない]
       │
       ▼
[朝ごはんを食べられない]
       │
       ▼
[授業中に眠くなる] ←── [疲れがたまる]
       │
       ▼
[家に帰ると疲れている]
       │
       ▼
[夜更かししてしまう] ←──（またスマホを触る）
```

### 根本原因（Core Constraint）

矢印が「原因」として最も多く出ているのは、**「夜更かししてしまう」**（またはその下の「スマホを触る」）。

- 「朝起きられない」は結果
- 「朝ごはんを食べられない」「眠くなる」も結果
- 全部を説明する原因は「夜更かし」に集約される

**根本原因 = 夜更かし（寝る時間が遅い）**

### 悪循環の確認

このCRTは輪になっている。夜更かし→朝起きられない→疲れ→また夜更かし、という**負のループ（悪循環）**。時間の遅れ（Unit 4）も関係している（「寝る時間」の影響が「朝の起きやすさ」に現れるまで時間がかかる）。

### ここで考えること

根本原因が1つに絞れたので、Unit 8 で「どう解消するか」を考える。

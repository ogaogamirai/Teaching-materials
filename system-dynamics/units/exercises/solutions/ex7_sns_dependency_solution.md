# EX7 — 解答・解説（SNS依存・情報過多）

> **前提:** この演習の狙いは「見るほど見たくなる」正のループと、「影響が後から出る」遅れを理解すること。SD 中心の演習。

---

## 1. 問題（UDE）の整理

- UDE1: スマホを確認する回数が増える
- UDE2: 集中が途切れる
- UDE3: 勉強・仕事が遅れる
- UDE4: 夜更かしで翌日の集中力が落ちる

## 2. SD の切り口（正のループと遅れ）

**正のループ（Unit 3）:**

```
通知が来る → スマホを見る → 次々に関連動画・投稿が出る
   ▼
「もっと見たい」が強くなる
   ▼
さらに見る →（最初に戻る＝強化ループ）
```

これは**正のループ（強化）**。見れば見るほど強くなる「雪だるま」です。

**時間の遅れ（Unit 4）:**

```
夜遅くまで見る →（← ここに遅れがある）→ 翌日、集中力が落ちる
```

SNS の影響は「今」ではなく「翌日・後で」出る。だから、なかなか気づかない。

**介入点（SD）:**
- 正のループを**切る**: 通知をオフにする（ループの入り口を断つ）
- 遅れを意識する: 影響が翌日に出ることを知って「今見る」を我慢する

## 3. TOC の切り口（根本原因）

**CRT で根本原因を探す（Unit 7）:**

```
[勉強・仕事が遅れる]
   ▼
[集中が途切れる]
   ▼
[スマホを確認する回数が多い]
   ▼
[通知が常に来る・見たくなる仕組み]  ← 根本原因（のひとつ）
```

**根本原因:** 「通知・無限スクロールという、見たくなる**仕組み**」が常に働いていること。「自分が弱い」ではなく、**環境（仕組み）** が原因。

**蒸発する雲（対立）:**

```
[目的C] 集中して勉強・仕事したい & 友達とつながりたい
   ／                              ＼
[要求A] 情報を取りこぼしたくない   [要求B] 集中を守りたい
   │                                  │
[行動A] 常にスマホを見る        ←→  [行動B] スマホを見ない
```

**前提（思い込み）:** 「通知を切ると、大事な連絡を見逃す」→ 実は**見る時間を決めれば**両立できる。

**Injection:** 通知はオフ、でも**1日3回だけ見る時間**を決める。これで「情報を取りこぼさない」と「集中を守る」の両方をかなえる。

## 4. 対比（SD と TOC の見え方の違い）

| 切り口 | 見えるもの | 答えたこと |
|---|---|---|
| SD | 正のループ（見るほど見たくなる）と遅れ（翌日に影響） | なぜ止まらないか。ループの入り口を切る |
| TOC | 根本原因（見たくなる仕組み）と対立（情報 vs 集中） | 何が原因か。前提を外して両立 |

- SD: 「見るほど強くなるループだから、通知という入り口を断つ」
- TOC: 「根本は『見たくなる仕組み』。通知オフ＋見る時間を決める、で情報と集中を両立」

## 5. Teach-Back 用の要点

- SNS 依存は「自分が弱い」のではなく、**正のループ（見るほど見たくなる）という構造**
- 影響は遅れて出る（翌日の集中力）から、気づきにくい
- 解決は「意志」でなく「**仕組み（通知オフ・時間を決める）**」でループを切る

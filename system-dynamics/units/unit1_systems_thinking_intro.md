# Unit 1 — システム思考の入り口：一直線？ それとも丸い？

> **対象:** 中学2年生
> **ゴール（L3 Teach-Back）:** 「一直線の考え方」と「丸い（循環する）考え方」の違いを、自分の言葉で人に説明できる
> **所要目安:** 15〜20分

---

## 1. Hook — まず2つの場面をイメージしよう

**場面A ドミノ倒し**

ドミノを倒し始めると、パタパタパタ…と次々に倒れていきます。
最後の1枚が倒れたら、**おしまい**です。

**場面B ブランコ**

こぎ始めると、ブランコは前後に揺れます。
揺れが止まりそうになったら、**もう一度こぐ**と、また大きく揺れます。

さて、この2つはどこが違うでしょう？

> **ヒント:** 「おしまいがあるかどうか」に注目してみよう。

- ドミノ倒しは **原因→結果で終わる**
- ブランコは **結果が原因に返ってくる**

この「**結果が原因に返ってくる**」ことを、**ぐるぐる回る＝循環（ループ）** といいます。

---

## 2. なぜこれを学ぶのか？（Value）

私たちは普段、物事を「AならばB」という**一直線**で考えがちです。

> 勉強した → 成績が上がる。（おしまい）

でも、現実はそんなに単純ではありません。

> 勉強した → 成績が上がる → 「やればできる！」と自信がつく → **もっと勉強する** → さらに成績が上がる → …

**結果が原因に返ってきて、ぐるぐる回っています。**

これを学ぶと、物事が**なぜ良くなっていくのか・なぜ悪くなっていくのか**が、ただの結果を見るよりもずっと深く分かるようになります。これが「システム思考」の入り口です。

---

## 3. この教材を最後まで学ぶと、どこまで分かるようになる？（ゴール像）

「システム思考」を全部で8つのユニットで学びます。最後まで学ぶと、こんなことができるようになります。

| レベル | できるようになること | 例 |
|---|---|---|
| **Unit 1〜4（見る力）** | 物事が「なぜそうなるのか」を、ぐるぐるの構造で説明できる | 「風邪が流行るのは、うつす→増える→さらにうつす、のループがあるから」 |
| **Unit 5〜6（直す力）** | 問題の「どこを直せばいいか」を見つけられる | 「部活で記録が伸びない原因は、練習メニューのこの工程がボトルネックだから」 |
| **Unit 7（総合力）** | 構造を見て、制約を直し、改善案を出せる | 学校の行事や係の仕事を、根拠つきで改善提案できる |
| **Unit 8（抽象化）** | 学んだことを自分たちの言葉でまとめ、新しい場面で使える | テスト勉強で学んだループの型を、部活・友達関係・将来の仕事に応用できる |

**つまり、ゴールは「知識を覚えること」ではありません。** 身の回りの出来事を「ぐるぐるの構造」として見て、「どこを直せば良いか」を自分で判断できる、という**一生ものの考え方**を手に入れることです。

---

## 4. 2つの考え方を比べてみよう（Reveal）

| | 一直線 | 丸い（ループ） |
|---|---|---|
| 形 | 原因 → 結果 | 原因 → 結果 → また原因に返る |
| 終わり | ある（結果でおしまい） | ない（ぐるぐる回る） |
| 例 | ドミノ倒し | ブランコ・PDCA・検証→改善 |
| 身近な例 | 消しゴムを使ったら減る（おしまい） | テスト勉強のやり直し |

**見分け方のコツ（これがUnit 1の最重要ポイント）:**

> **「結果」が「原因」に返ってきて、もう一度その原因を動かすかどうか。**

返ってくる → ループ。返ってこない → 一直線。

---

## 5. 例で定着 — テスト勉強と部活（Interact）

### 例1: テスト勉強

1. テストで悪い点を取った
2. → 「勉強のやり方が悪かった」と気づく
3. → やり方を変えて勉強する
4. → 次のテストで点が上がる
5. → 「このやり方が効く」と自信がつく
6. → **3に戻る**（さらに良いやり方を試す）

ここで「点が上がった（結果）」が「もっと勉強する（原因）」に**返ってきています**。これがループ。

### 例2: 部活の練習メニュー

1. 大会で負けた
2. → 「基礎が足りない」と気づく
3. → 練習メニューを見直す
4. → 次の大会で記録が伸びる
5. → 伸びたことを確かめて、**3に戻る**（さらに改善）

これもループです。これを「**改善のループ**」と呼びます。

> **やってみよう:** 上の例2の、どこで「結果が原因に返っている」かを指さしてみよう。

---

## 6. Check — 判定問題（これは一直線？ それとも丸い？）

それぞれ「一直線」か「丸い」か、理由つきで答えよう。

1. リンゴが木から落ちた。（→ 落ちたらおしまい）
2. 友達と仲良くすると笑顔が増える → さらに仲良くしたくなる。
3. お菓子を食べたら無くなった。
4. 走ると速くなる → 速いと楽しい → もっと走る。

> **答え合わせ（下を見る前に自分で答えよう）:**
> 1. 一直線　2. 丸い　3. 一直線　4. 丸い

---

## 7. よくある誤解（Misconceptions）

| 誤解 | 正しい理解 |
|---|---|
| 「ループ＝同じことの繰り返し」 | 同じじゃなくて、**結果が原因に返って、前より変わる**。改善のループは、回るたびに少しずつ良くなる |
| 「PDCAは仕事のやり方で、自分には関係ない」 | テスト勉強・部活・趣味の練習、全部 PDCA と同じ構造 |

---

## 8. Teach-Back — 素人に説明しよう（ゴール）

次のテンプレで、「一直線と丸いの違い」を、システム思考を知らない人に説明してみよう。

1. **何の話か:** 「物事の見方には、一直線と丸いの2つがある」という話
2. **部品は何か:** 原因・結果・「結果が原因に返る」こと
3. **どう繋がるか:** 原因→結果→また原因に返ると、ぐるぐる回る（ループ）
4. **例:** テスト勉強（点が上がる→自信→さらに勉強）
5. **よくある誤解:** ループは同じ繰り返しじゃなく、回るたびに変わる
6. **素人への一言:** 「ドミノは倒したら終わり。ブランコはこげばまた返ってくる。物事をブランコみたいに見る考え方だよ」

---

## 9. まとめ（Takeaway）

- 物事の見方は **一直線（原因→結果で終わる）** と **丸い（結果が原因に返る）** の2つがある
- **結果が原因に返る**ことを「循環（ループ）」という
- テスト勉強・部活・PDCA・検証→改善は、みんな**ループ**
- 次回は、この「ループ」の中身（何がたまり、何が流れるか）を詳しく見ていく

> **次回予告 (Unit 2):** ループの中にある「たまるもの（ストック）」と「流れるもの（フロー）」を見つけよう。

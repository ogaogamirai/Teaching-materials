RSAの順方向と逆方向

2つの素数を掛けて数を作るのは簡単ですが、結果から元の素数を探すには試行が必要です。

これはRSAの安全性の考え方を学ぶ模型です。ここで使う小さな数は安全な通信には使えません。

n = p × q
順方向：すぐ作れる

秘密の材料 p と q を掛けます。

逆方向：候補を探す

公開された n を割り、元の p と q を探します。

逆方向では何をしているか

公開された n に対して、候補 2, 3, 4, ... を順に割っていきます。余りが0になった候補が、nの約数です。

もし n=p×q で、pとqのどちらが小さいか分からなければ、小さい方は必ず √n 以下です。したがって、まず 2 から √n までを調べれば、相手の約数を見つけられます。

モデルでは試した候補を表示します。候補が増えることが「逆方向の難しさ」の最初の体験です。

観察すること

  • pとqを掛ける計算は1回です。
  • nから戻すには、割り切れる候補を順に試します。
  • 数字が大きくなるほど、単純な探索の候補が増えます。

実用RSAでは、単純な試行以外の高度な攻撃法も考慮し、非常に大きな数と安全な方式を使います。

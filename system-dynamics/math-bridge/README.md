# math-bridge — 理論ルート（数理前提の補助Unit）

> 発展編（大学レベル）で使う数式の**前提だけ**を学ぶ補助Unit群。
> 網羅的な数学教科書ではない。各ユニット発展編の「必要な前提」として使う。

---

## 使い方

- 発展編の冒頭に「**必要な前提: math-bridge のB◯まで**」と補記されている
- 中2はその範囲を先に読んでから発展編へ。数学が得意な人はスキップ可
- 各Unitは短め（10〜15分）。1つずつ順番に

## 記法について

- 数式は **LaTeX 記法**（`$...$` / `$$...$$`）で書く
- 将来の HTML 化時に KaTeX で綺麗に表示できるようにするため
- Markdown 段階では `$$` ブロック + 日本語説明で併記する
